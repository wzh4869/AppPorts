# Agent Note: 简易与高级迁移模式

Status: proposed

## Problem

用户在迁移和还原时会遇到多种迁移方式、签名选项和异常处理入口，难以预测默认操作及结果。多种方式叠加也扩大了常规迁移需要验证的场景。

## Proposal

默认进入简易模式。简易模式以迁移、还原、查看进度和处理异常为主，固定支持场景的迁移方式。微信账号默认只迁移 `msg/file` 和 `msg/video`，数据库、配置和其他附件留在本机。确认页展示迁移范围和共享文件仍占用内盘空间的影响。

应用本体拟使用普通迁移及非锁定方式，默认关闭更新守护。普通应用数据拟仅支持验证过的目录和软链接迁移，沙盒容器数据使用 APFS 挂载并保留应用签名。外盘条件、应用兼容性或版本冲突无法安全确认时，说明原因和下一步操作。

高级模式仅从设置开启。用户须阅读并确认风险与免责说明，再点击开启。传统链接、锁定迁移、经典容器迁移、手动重签、微信其他迁移范围、自选和工具目录、旧链接接管及强制处理拟在高级模式开放。强制处理继续按具体操作确认。两种模式共用迁移记录和安全校验，关闭高级模式后仍可挂载、解锁、还原和清理既有迁移。

## Alternatives considered

- 保留全部选项并高亮推荐项。改动较小，常规用户仍要理解各选项，复杂组合也仍出现在普通流程中。
- 删除低频功能。维护范围最小，但历史迁移及确有需要的用户仍需要旧链接处理和明确的强制恢复入口。

## Acceptance criteria

- 默认进入简易模式。开启高级模式需要明确确认风险与免责说明，取消后仍在简易模式。
- 微信新迁移默认仅大文件与视频。应用数据按类型执行固定迁移方式，已创建的任务和历史迁移仍可正常处理。
- 发布前验证应用和数据的迁移、还原、断盘、权限不足、空间不足、退出应用、取消、重启恢复、无关 APFS 镜像重复挂载及旧副本清理。
- 微信覆盖只有一个可迁移成员、与本地附件共享文件、部分迁移后断盘、逐个成员还原及清理失败。使用专用测试盘验证内容、签名、实际空间与状态一致。
- 高级模式验证入口、风险确认、操作范围和基础数据保护，已验证兼容性按场景记录。

## Risks

仅在界面隐藏动作可能遗漏右键、任务详情或排队任务入口，实施时需核对实际执行入口。已有迁移必须保留恢复路径。微信所选范围可能因共享文件而实际释放较少空间。
