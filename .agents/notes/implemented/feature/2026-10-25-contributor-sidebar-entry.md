# Agent Note: 贡献者指南进入三语侧栏

Status: implemented

## Problem

贡献者指南有完整开发与提交流程，但只列为辅助页，用户在文档侧栏找不到它。页面可直接打开且首页页脚有入口，仍需要离开当前文章才能定位贡献说明。

## Decision

`User_docs/config/docs-navigation.json` 将 contributing 从 auxiliary 移到 main，放在 sponsor 紧后，保留首页页脚“参与贡献”入口。三语复用已有“贡献者指南”译名、页面与固定章节 ID，URL 和正文不变。每种语言的 28 篇文章全部进入主目录，名词解释继续为末项，原有四个分组不变。

沿用已有页面树生成与图标机制；侧栏、上一页和下一页由同一棵树生成，因此贡献者指南也进入页面间导航。生成器保留 auxiliary 字段兼容结构，当前数组为空，不新增隐藏文章。

现有 docs:check 校验主目录总数、空辅助清单和紧邻 sponsor 的位置，并核对全部 84 篇导出文章的侧栏含本语言贡献入口、三个首页的页脚仍有贡献链接。README 同步说明全部文章进入侧栏。

## Existing note audit

- [面向普通用户的文档结构](../architecture/2026-10-15-reader-first-docs-structure.md)：部分取代。旧方案将开发细节放在唯一辅助页，目的是保持普通用户主目录聚焦；本篇改用侧栏入口提升可发现性，保留原文的取舍与其余两层目录、末项词汇表及读者导向原则，双方互链。
- [三语文档站替代旧站](../architecture/2026-10-15-three-language-docs-replacement.md)：语言、路由与部署契约相关，不改变决定，无需归档。
- [贡献流程入口](../process/2026-10-25-contributor-workflow-entrypoints.md)：正文同步规则相关，不改变贡献流程。
- 按 contributing、辅助页与主目录检索 proposed、implemented、rejected，未发现同题提案或完全吸收的笔记；无归档或删除。

## Alternatives considered

- 只保留首页页脚入口：主目录更精简，但文档内阅读时难以发现贡献流程；本次用户明确批准增加侧栏入口。
- 归入“帮助与支持”：能减少顶层条目，但用户已批准放在赞助后作为项目参与入口，采用独立条目而不扩展帮助组。

## Consequences

三语读者可直接从任何文档页的侧栏进入贡献者指南，页脚入口继续可用。代价是顶层导航增加一项，赞助之后的上一页／下一页顺序也加入贡献指南。源码文章总数、路由、语言和发布方式不变；本地构建不等于网站已上线。

## Verification

`docs:build`、`docs:typecheck`、`docs:check` 均通过，覆盖 84 篇文章、87 个页面、三语侧栏链接及三个首页页脚入口。浏览器桌面预览逐一从简中、繁中和英文简介页点击新增入口，均打开对应语言的贡献者指南，侧栏位置在赞助之后，当前条目正确高亮。没有新增页面、路由、译文或手机布局；本轮未执行手机尺寸预览及未修改的搜索、主题交互。

笔记目录、格式和归档三项门禁通过（67 篇笔记、0 篇归档），`git diff --check` 通过。应用代码未修改，未运行 Xcode 构建或真实磁盘测试；未提交、推送或部署站点。
