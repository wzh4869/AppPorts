# Agent Note: 设置内嵌准备检查与 App Store 引导状态

Status: implemented

## Problem

设置中的准备检查需要再次打开面板，用户不能直接看到缺少哪些权限。App Store 引导仅检查外盘根 Applications 目录，点击“我已设置”会创建目录，未检测真实开关，还可能因目录存在漏掉未完成的配置。“稍后”没有持久状态，用户无法明确停止重复提醒。

## Decision

设置页直接显示完全磁盘访问、App 管理和外部存储的实际检查结果。ReadinessCheckModel 复用 LaunchReadinessChecker，统一拥有检查中状态、结果和 PermissionReadiness 同步。“检查”按钮和权限提示点位于“准备情况”标题右侧，刷新页面内准备结果与 App Store 状态，检查期间沿用禁用状态；移走按钮后取消空出的设置页头，内容直接进入卡片。欢迎屏与独立检查入口继续共用原卡片和权限操作。内嵌准备结果位于右上方应用信息卡片内，使用共同边界、字号和分隔线，不额外嵌套卡片或打开检查 sheet。已就绪时显示紧凑的名称与状态行，详细说明放在 help；未就绪时保留说明与操作。应用信息保留 48 点图标、版本、实际运行路径和原有更新及链接控件。经典模式确认保持原规则。

AppStoreExternalInstallSettings 共用于主界面提醒和设置状态。检测只读当前用户 com.apple.appstored 域的 PreferredVolume，使用 CFPreferencesSynchronize 和 CFPreferencesCopyValue，核对 volumeID 与所选外盘根的卷 UUID。App Store 界面初始化以记录是否非空设置开关，关闭分支调用 clearPreferredVolume；只读实机探针的记录与系统界面的 hano 选择一致。本产品不动态调用 Apple 私有 getter，不修改 App Store 偏好或切换系统开关。

记录为空表示未设置，有效卷身份与迁移目标一致时显示勾和实际 Applications 目录。目录来自现有 AppMigrationService.masApplicationsURL，说明 AppPorts 会把用户选择迁移的 App Store 应用放到这里；App Store 对新下载的大于 1 GB 的应用使用此盘。已设置不提醒。系统选了另一块盘时显示不一致和操作入口；记录损坏、查询失败或所选盘不可读时不声称已设置，也不以离线状态要求重新配置。

未设置且没有关闭提醒时，在选择或恢复外部存储、回到前台时显示引导。正在操作或位于设置页时不另弹引导，设置页直接提供配置入口。“不再提醒”保存 AppPorts 自己的全局偏好，Esc 复用这个明确的取消动作；用户仍可从设置打开 App Store 设置。“我已设置”只重读真实状态，通过后刷新扫描，未通过继续引导，不创建 Applications 目录来伪造完成。沿用三个按钮，正文以 gearshape 与“设置”并列说明后续入口。

版本保持 2.2.1，初始完整实现 build 为 57，包含[更新守护登记修复](../bug-fix/2026-11-16-更新守护不占用应用启动登记.md)。维护者补充要求说明 AppPorts 迁移不受 1 GB 门槛限制，build 58 仅同步更新迁移目录前的说明和中英文，不改变实际迁移流程；小于 1 GB 的 App Store 应用仍可由 AppPorts 迁移。十二条新增文案完成 en、zh-Hans、zh-Hant，其余语言按维护者授权暂用英文，不填写假的 translated 状态，不放宽翻译审计。

## Alternatives considered

- 保留目录存在检查：最小且不依赖系统字段，但点击“我已设置”创建目录便会误报，无法满足实际配置判定。
- 动态调用 ASFVolumeMonitor getter：能直接共享系统接口，但增加私有框架和符号依赖；已核对记录来源后采用只读 CFPreferences，并保留未知状态。
- “稍后”改为下次重开继续提醒：可以持续提示，但维护者选择“不再提醒”并保留设置入口，因此持久保存选择。
- 保留准备检查面板：能沿用整个容器，但多一次点击且遮挡设置内容；只抽出检查模型，卡片和其他独立面板继续复用。

## Consequences

用户可直接查看准备结果、App Store 配置和未来迁移目录，明确停止引导后仍可补做。检查共用生产实现，仅由用户与相关事件刷新，不新增轮询。

App Store 偏好键不是公开稳定接口，系统改变记录时需重新核对；格式异常显示无法确认。停止提醒覆盖后续选盘，用户可从设置手动配置。新版不改变 App Store 设置，不自动迁移应用，也不创建完成标记目录。

最终同批源码的完整 runner 验证与已知英文回退审计缺口见 [build 61 验证记录](../../../../.github/pr-assets/settings-build61.md)。全量结论以该记录为准，早期阶段的未运行声明只描述当时验证范围。
