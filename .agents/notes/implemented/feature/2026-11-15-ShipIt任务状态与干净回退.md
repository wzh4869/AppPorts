# Agent Note: ShipIt 接手展示与用户主动回退

Status: implemented

## Problem

ShipIt 更新接手仅写日志和安装收据，用户无法从任务中心判断 AppPorts 是否参与、正在等待什么或是否完成。用户要求失败任务提供回退更新按钮，并明确拒绝把本次更新材料搬到新的归档目录。

## Decision

跨进程展示由[后台更新守护与主窗口设置](2026-11-16-后台更新守护与主窗口设置.md)扩展：更新代理按请求发布独立状态，主程序导入任务中心并保留回退入口；进程身份仅影响运行或待处理的展示。安装收据、回退意图及本篇恢复后清理规则不变，展示历史仍不能授权文件操作。

任务中心为每次独立接手保留一条记录。等待、错误、重试和最终结果都更新这一条。若 ShipIt 复用已成功收尾的请求又安装失败，守护核实新一轮安装证据后，单独记录第二次接手。判定依据见[ShipIt 更新失败自动接手](2026-11-15-ShipIt更新失败自动接手.md)。展示历史不能取得操作锁或驱动恢复。展示任务不提供迁移暂停、取消或迁移异常处理操作；失败后提供主动回退入口。新版签名明确被拒时，自动回退的条件与清理范围见[新版验签失败后自动回退](2026-11-21-ShipIt新版验签失败后自动回退.md)。历史保留沿用原设置。

用户在设置中关闭守护时，代理读回该设置，取消正在等待或执行的接手。任务中心显示「已暂停自动处理」，保留应用仍待恢复的说明。展示文件沿用现有 `cancelled` 状态，旧版 AppPorts 仍可读取历史；安装收据不变。下次开启后，只有现场仍符合恢复条件才继续。单独收到终止信号不能说明用户关闭了守护：更新或替换程序时中断的任务仍待检查，已知的实际错误保留原因和回退入口。

主动回退停止该请求的自动接手，仍通过操作 token、每次尝试独立的 `OperationLock.freshInstance()` 和启动保护执行；刷新本地入口前显式释放外层锁避免同进程重入。优先使用安装收据记载的原应用身份；目标缺失时只从同轮 ShipIt 移动日志识别旧版临时位置，并同时比较 `shortVersion` 与 `buildVersion` 判断更新包确属更高版本。只有完整签名有效且位置和身份可确认的旧副本才允许恢复。恢复到原外盘路径并刷新本机入口，不回迁到本机、不重签、不读写聊天和设置。

旧版完整恢复、签名校验和入口刷新后，直接清理本次请求对应的下载缓存、临时副本、安装恢复状态和 AppPorts 多余副本。不创建归档目录。删除前检查所属路径及文件系统身份；回退失败保留继续恢复所必需的副本和操作记录，不报告成功。回退意图在等待操作 token 和寻找旧版前原子保存，防止准备失败或中断后继续安装同一新版。既有安装检查点也尊重意图。清理完毕先保存终态再删除安装收据和回退记录，中断后独立校验恢复目标并收尾。记录逐文件解析、按请求去重，展示历史不能成为文件操作授权。

## Existing note audit

- [首次接手](2026-11-15-ShipIt更新失败自动接手.md)部分扩展：正常失败接手保持原规则，新增用户主动回退。
- [旧版保留与收尾](2026-11-15-ShipIt旧版保留与更新状态收尾.md)部分取代：自动接手仍保留原备份；用户主动回退成功后清理本次多余副本，不长期归档。
- [事件调度](2026-11-15-ShipIt事件触发检查.md)部分扩展：观察更新状态，同一请求回退时停止自动接手。
- [后台任务](../architecture/2026-10-21-后台迁移任务与异常处理.md)部分扩展：只新增观察记录，不改变受调度迁移的并发与租约语义。
- proposed 与 rejected 未发现其他同职责提案；不吸收无关记录。

## Alternatives considered

- 把接手作为普通迁移任务提交：可直接获得显示和控制，但既有监控器已持有独占 token，任务中心又持锁且有暂停/取消语义，会重复调度并改变原恢复边界。只观察既有执行。
- 把失败材料移到归档目录：可保留全部副本，但用户明确要求干净回退、反对长期占盘；恢复成功后删除本次材料，恢复失败仅保留必要副本。
- 用同名或相似版本搜索旧应用：实现容易，但不能确认是更新前的那份应用；只接受安装收据身份或同轮原目标移动记录。

## Consequences

没有完整旧版时无法承诺回退，显示原因并保留现场。外盘不可写或应用拒绝正常退出时回退等待或失败，不强退。展示状态不替代持久收据；完成按钮结果只在实际恢复和本次清理均成功后发布。

任务观察不占迁移调度名额、不获取执行租约；代价是历史的两个可选字段及回退状态记录。完成历史仍沿用原有退出清理设置。回退成功删除本次状态记录，失败只保留用于阻止重装和继续恢复的记录及必要副本。此前人工测试的历史备份不在本次清理范围。
