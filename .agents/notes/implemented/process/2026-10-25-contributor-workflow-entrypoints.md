# Agent Note: 贡献入口区分合并门槛与验证责任

Status: implemented

## Problem

根目录与文档站三语指南没有公开决策笔记要求、首次开发环境及文档贡献验证路径。专项测试在贡献指南中是建议项，在 AI 工作规范中是必须项；本地化又把完整翻译与代码接入混为可选。贡献者仅按公开入口执行时，无法知道自己需要提交哪些证据。

## Decision

`CONTRIBUTING.md` 是公开贡献流程入口，保留中英文；文档站三语保存完整对应说明与既有章节 ID。共享规则更新同时核对这些入口及 PR 模板，不引入新的生成工具或 CI 门禁。

仓库使用 main 作为开发与发布主分支，贡献分支从最新 main 创建，PR 直接以 main 为目标。旧指南中的 develop 是不存在的分支，入口及 PR 模板按维护者确认修正，PR 与合并后工作流只监听 main；手动触发和各验证步骤不变。CLAUDE.md 继续保留任何修改前须先说明方案并获得明确批准的策略，本次不启用目标内自主修改。

重要功能在开发前可通过 Issue 讨论，也可加入 [QQ群 (384270587)](https://qm.qq.com/q/BhhRJ2rDz4) 与群主讨论；后一条路径由群主在 Issue 公示讨论结论，核心功能获得确认后再开发。指南各语言、CLAUDE.md 与 PR 模板提供同一流程，PR 关联公开 Issue，群聊不替代公开决策记录。

贡献流程不要求或建议使用多个 AI 模型交叉验证；保留贡献者人工审查、相关测试和核心功能手动验证责任。

PR 自动门槛继续只有 Release 编译，外部贡献者的相关专项测试仍为建议。AI 修改已有测试覆盖的模块时必须运行对应测试。合并后应用回归及进程计时测试必须通过，本地化仍为 Advisory；修改共享复制、扫描或传输基础逻辑时，推进 main 前按 CLAUDE.md 在隔离 runner 完成完整验证。指南链接 CI 共用脚本，不复制其完整测试编排。

完整翻译可以延后，但新增 key 入目录、AppKit 文案显式本地化、动态文案使用格式化 key 与语言列表集中管理仍是代码接入要求。延后翻译在 PR 中说明文案、语言、实际回退与后续计划。指南和本地化说明保持一致，不放宽任何审计断言。

纯文档改动运行文档验证，不要求无关的应用编译；涉及应用源码或构建输入时仍要求 Release clean build 和对应测试。文档站贡献链接其 README 与 AGENTS，保留三语同步与生成目录边界。开发环境说明区分运行系统与开发工具链；仓库没有验证过最低 Xcode 版本，因此提供当前 CI 工具链的查询入口而不猜测最低版本。

## Alternatives considered

- 仅在 CLAUDE.md 保留完整规则：避免多份维护，但没有 AI 的贡献者会漏掉提交要求，故公开入口也提供简明规则及权威来源链接。
- 将所有专项测试和完整翻译设为 PR 硬门槛：要求统一且易于解释，但改变现有外部贡献政策；保留现有门槛，明确各角色责任与未完成项证据。
- 从单一文件自动生成全部指南：能减少漂移，但需要新增工具链与章节映射。本次保留现有文件，明确同步责任并复用现有三语章节检查。

## Consequences

首次贡献者可从公开指南找到开发、测试、翻译、文档与决策笔记的交付路径；AI 和外部贡献者的要求不再因 Advisory 一词混淆。代价是根目录双语与站点三语仍需人工同步，现有检查只能验证章节和链接，不能保证语义一致。若重复漂移，再评估生成共享规则。

## Verification

修改范围为贡献流程文档、模板、本笔记及 CI 的目标分支过滤；不涉及应用代码，未运行 Xcode 编译或应用测试。CI 工作流与修改前逐字比较，唯一变化为移除 develop 过滤项，所有检查步骤保持不变；Ruby YAML 解析确认 PR 与 push 目标均为 main，手动触发保留。另断言 CLAUDE.md 的任何修改前明确批准规则原文保留。

`User_docs` 下的 `docs:build`、`docs:typecheck`、`docs:check` 全部通过；静态检查覆盖 84 篇译文、87 个页面、内部链接和锚点、Markdown 导出、导航、退出路由与公共资源。另与修改前逐项比较贡献者指南的固定章节 ID、顺序及标题层级，并核对所有新增测试入口名称在当前测试源码中存在。三语桌面浏览器抽查覆盖开发环境、测试表、决策笔记和文档贡献说明；本轮没有执行手机尺寸预览，也没有重新测试搜索、主题等未修改的站点交互。

笔记目录、格式及归档三项校验通过（66 篇笔记，0 篇归档）；`git diff --check` 通过。现有三语章节门禁不能证明译文语义一致，翻译范围与角色要求由人工逐段复核。

AI 指令入口的内容范围见[精简 AI 指南](2026-10-25-concise-ai-guide.md)，架构与历史事实按需查源码和既有笔记。
