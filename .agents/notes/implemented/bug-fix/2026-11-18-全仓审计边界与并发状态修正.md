# Agent Note: 全仓审计边界与并发状态修正

Status: implemented

## Problem

全仓静态与单测审计暴露多处跨模块边界及生命周期缺口：

- `FolderMonitor` 共享全局并发队列、`open(O_EVTONLY)` 未带 `O_CLOEXEC`，且 `cancelHandler` 通过 `[weak self]` 关闭描述符，监控对象提前释放或重复启动时会遗留外置盘目录描述符。
- `DurableFileIO.syncTree` 将根目录排除名递归传入子目录；`CustomDirValidator` 未解析软链目标即放行目录位置校验；`SignatureSnapshot.validateLinksForSigning` 对悬空软链仅调用失败即跳过的 `realpath`，漏掉指向包外的悬空软链。
- `ContainerVolumeMigrator.mountVolume` 在 `diskutil` 已报告挂载点但 `statfs` 尚未可见时直接抛错退出，未等待挂载表同步；`DataTransferRecord` 与 `ContainerMountStore.finishAutomaticMountRollback` 未纳入 `.appports-deleting-<id>` 隔离目录，可能提前归档仍有残留隔离目录的回滚记录。
- `MigrationTaskControl.checkpointAsync` 在临界区仍允许暂停挂起；`AppOperationState` 仅在迁移计数归零时完成退出回调，未覆盖签名等普通操作；`AppUpdateProtectionStore` 缺少锁保护且在 `commitSameObjectMove` / `commitExchange` 后丢失 `adoptedLegacyLock` 标记。
- 本地 `.deepContentsWrapper`、文件夹镜像入口与 iOS bash 入口直接在目标路径原地构建，中途失败会留下半成品入口；`AppScanner` 未读取 `Wrapper/*.app` 结构的 iOS 包信息；`OperationMaintenance` 自动恢复软链传输时未按 `interactive` 关闭管理员密码弹窗。

## Decision

在不改变外部落盘格式和既有产品交互的前提下，收紧上述运行时不变量与错误边界：

- `FolderMonitor` 改为私有串行队列与互斥锁保护，`open` 附加 `O_CLOEXEC`，`startMonitoring` 先停止旧源，`cancelHandler` 直接捕获独立描述符值并在对象析构后仍可靠关闭。
- `DurableFileIO.syncNode` 仅在根层应用 `excludingRootEntries`，递归子目录传空集；`CustomDirValidator` 同时检查字面路径与解析软链后的真实路径；`SignatureSnapshot.validateLinksForSigning` 先检查软链字面目标并沿最近存在祖先解析 `realpath`，拒绝指向包外的悬空软链。
- `ContainerVolumeMigrator.mountVolume` 在 `.reportedByDiskUtil` 分支轮询等待 `statfs` 可见并核验所有权，不再对已挂载路径重发挂载命令；`DataTransferRecord` 将 `preparationQuarantinePaths` 纳入 `materialPaths` 与回滚拓扑，`finishAutomaticMountRollback` 在附件材料非空时拒绝结案。
- `MigrationTaskControl` 在进入临界区时广播唤醒挂起任务并在异步检查点跳过暂停等待，单目录 `DataTransferProgress.track` 退出时兜底重置临界区标记；`AppOperationState` 在 `setMigrationCount` 与 `finish` 双路径统一检查空闲后完成退出应答；`AppUpdateProtectionStore` 复用 `AppTransferStore` 递归锁并在路径更新、同对象移动和原子交换中保留 `adoptedLegacyLock`。
- 三类非编译型本地入口统一先在同目录 `.appports-create-*` 暂存目录内构建，完成后原子移动就位，失败即清理暂存目录；`StubLauncherSource` 编译命令检查 `proc.run()` 错误。
- `AppScanner` 增补安全包内路径遍历，支持 `WrappedBundle`、`Wrapper/*.app` 与包根 `Info.plist` 的 iOS 元数据读取与类型识别；`OperationMaintenance` 按 `interactive` 传递 `DataDirMover(allowsAdministratorPrompt:)`；`AppMigrationService` 在测试注入独立 `AppTransferStore` 时默认隔离更新缓存目录。

## Alternatives considered

- **在 `.reportedByDiskUtil` 分支直接回到外层 `mountVolume` 重试循环**：写法更短，但外层循环会再次抢占挂载点租约并对已由 `diskutil` 挂载的目录重发挂载命令；改为内层仅轮询 `statfs` 与所有权同步。
- **放宽 `AppLibraryImageFileAccess.Request.source` 使其接受普通文件**：无需新增枚举分支，但会削弱 `.sparsebundle` 映像源必须是目录的校验；新增独立的 `.linkTarget` 分支分别守住映像源与受管文件软链。

## Consequences

监控器切换与释放不再遗留外置盘描述符，切换临界区不再因异步检查点被暂停卡住，应用退出等待覆盖全部活跃操作，半成品本地入口与包外悬空软链在落盘或签名前即被拦截。

`AuditRegressionTests` 新增描述符关闭、根排除范围、软链目录逃逸、包外悬空软链、映像内 `.plist` 普通文件链接、软链父目录下未创建监听文件与 `Wrapper/*.app` 扫描回归。部分极端竞态（如内核挂载表延迟同步）由受控单元路径覆盖，仍不等同于全部第三方外置硬件的实机压测。

经维护者授权，构建号由 `70` 升至 `71`（`2.3.0 (71)`），使用续期后的同一团队 `Apple Development` 证书（`TeamIdentifier=MQ7XG7WM3F`，指定签名要求与旧版一致）完成双架构 `arm64`/`x86_64` Release clean build 与严格整包签名校验；在持有共享操作锁下暂停后台代理并执行 `RENAME_SWAP` 同卷原子替换 `/Applications/AppPorts.app`，启动后新主进程与更新守护正常运行，两份 `LaunchAgents` 定义均已更新为新构建 `CDHash`，旧暂存包核验无打开文件后清理。
