# Agent Note: 面向普通用户的文档目录与内容深度

Status: implemented

> 三语范围与旧站退出由[三语文档站替代方案](2026-10-15-three-language-docs-replacement.md)接管；本篇保留当时的取舍与仍有效的框架或内容约束。

## Problem

原中文站的 31 篇正文混合了操作、底层机制和故障诊断。数据迁移分散在基础实现、工具识别、挂载、签名和身份页面；FAQ、故障排除与日志又重复部分内容。普通用户为完成一次迁移，需要先辨认技术类别。

实验篇幅过长，旧文将有限样本概括为普遍规律；设置、签名、默认迁移方式也与当前开发版本存在偏差。精简不能丢失必要限制和历史功能，旧应用帮助链接仍需可用。

## Decision

当前操作正文按 AppPorts 2.0.0 build 50 的实际代码和界面整理，不以工程版本号推断下载渠道已发布；历史版本和实验继续保留原始基线。操作、原理、博客和参考条目各自承担不同阅读任务，目录最多两层；不要求用户先研究内部机制或运行终端命令。

主目录包含 27 篇，顺序由 User_docs/config/docs-navigation.json 唯一描述：简介、快速开始、迁移应用、迁移数据、还原／接回／解除链接、外置盘与日常使用；原理组五篇；博客组包含索引与两篇文章；帮助与支持三篇（常见问题、macOS 27 修复、目标盘存不住的应用信息）；设置、更新日志、赞助；历史功能归档组四篇；开源许可、隐私政策、名词解释。没有“使用指南”分组，名词解释是主目录最后一项，保留原 glossary URL。

简介保留产品介绍、文档用途、DeepWiki 参考与作者博客来源链接，以及透明体验、策略稳定、低系统负担、广泛国际化、无障碍友好五项产品哲学。政策与许可保留完整条款和主目录入口，贡献者指南作为辅助页保留开发细节。贡献者页的导航位置由后续[贡献者指南进入侧栏](../feature/2026-10-25-contributor-sidebar-entry.md)决定部分取代，其余目录和内容原则继续适用。四篇历史归档进入主目录，贡献者页为唯一辅助页，共 28 篇中文页面。

### 正文与版本边界

操作文章说明适用范围、准备、步骤、可观察结果和问题入口。原理集中在一个分组，不把内容堆成一篇长文。术语首次出现时给必要解释，再链接名词解释或主解释文章；链接不能代替必需步骤。

按钮按当前界面核对：应用使用“迁移到外部”“迁移回本地”，删除入口是行末垃圾桶；默认容器“迁移”执行挂载流程，经典模式下才单列“挂载迁移”。准备情况检查权限、连接、格式和加密，本次容量与安装位置以操作检查为准。

当前迁移与手动签名分开，所有系统停用登录自动重签。恢复原始签名与再次重签不同；官方覆盖安装外置应用前先迁回，完整备份或匹配原件可直接修复外置应用。签名待检查不能等同于签名损坏，签名已替换也不证明数据损坏。APFS 的要求仅用于相应容器挂载迁移；2.0.0 加密目标为新数据卷单独设置密码，可选保存到本机钥匙串，不再沿用早期未加密限制。

签名原包行为起于 1.9.1 build 31，依据公开提交 b774424 并核对当前界面：官方原包自动保存到合适外盘的可见 AppPorts Backups 目录，附 README.txt；不新增目录选择或备份管理入口。设置页集中解释选盘顺序、内部临时空间、恢复和删除影响，FAQ、外置盘、修复与名词解释只保留必要说明并链接。旧原包迁出须验证完成，旧身份记录仅在没有操作依赖且来源已另行保留或官方安装已验证时退休；离线不能视为缺失。不把服务内部的重复重签能力写成当前菜单操作，已确认重签时菜单只保留恢复。正常设置不再显示登录自动重签开关，仅清理失败时显示重试。

数据操作页解释锁定结构默认隐藏、状态筛选、用户目录入口、大小口径和分阶段进度；列表能否提供操作与执行前检查分开，复制百分比不能当作整次迁移完成。更新日志只提炼用户可观察变化，当前标明 2.0.0 build 50，并保留此前开发阶段记录；本次对话中的私人设备路径、清理清单和测试应用明细不进入公开操作页。隐私政策同步自动选盘所需本地信息、外盘原包和内部恢复记录，修正“卸载即可清除全部本地数据”的过时表述；其余权利、网络接收方和许可条款保留。博客的 468c788 研究基线与历史实验版本继续保留，签名存储更新不改写其原始证据。

### 2.0.0 当前操作说明

三语操作页以当前代码核对任务中心、加入后台、暂停／取消安全收尾、历史展示、数据清理选择和应用强制回迁。总体进度是阶段与目录合算的估值，当前目录阶段单独说明，不能再把全部百分比写成复制比例。强制回迁跳过内容校验、保留材料和未完成状态的限制必须保留。

主动弹出说明针对整块物理盘及所有卷；先暂停自动挂载，再请求 Finder 弹出，发送请求不证明完成。恢复只由设备重新连接触发，没有手动取消暂停入口。启动保护仅涵盖已更新的原生 macOS portal，不承诺拦截所有启动方式。隐私政策的本地存储清单列出任务历史、弹盘暂停与启动协调锁。

微信账号说明覆盖整体与媒体拆分迁移、切换前完整还原及离线可用性边界；加密目标说明独立密码、可选本机钥匙串与未保存密码时人工解锁，隐私政策相应修正“不访问钥匙串”的旧断言。应用页说明索引排除会移动真实应用至专用库，缓存刷新不等于删除业务文件。博客的加密限制绑定原固定提交，并链接当前能力，不更改历史实测。

storage-capabilities 在三语共享导航中归入帮助与支持，保留 slug、正文与应用帮助链接；不新增页面或改变两层目录契约。更新日志增加 v2.0.0，保留 v1.9.1 开发历史和旧章节 ID；研究博客不以本次正文核对替换原实验版本或扩大实测结论。此为现有读者导向结构的事实同步，不改变框架、语言和路由决定。

### 博客与研究证据

博客是用户批准新增的深入阅读入口，沿用现有 Markdown、搜索、目录图标、页面操作和导出能力；顶部导航、首页页脚与侧栏均可到达 blog/overview。blog/why-mount-and-apfs 串起符号链接、原生挂载、磁盘映像、断开存储和自动接回的取舍；blog/data-migration-boundaries 解释系统结构、微信额外规则、临时目录生命周期、父子关系和复制期间写入。博客承担单轮条件、结果与跨实验论证，操作页不承担长篇论证。原六篇研究源文件退出正文、导航与搜索，证据与限制融入博客对应章节。

博客采用摘要、问题、方法、对照结果、讨论、限制与参考资料，不设关键词栏。当前产品事实绑定公开提交 468c788，并标为 1.9.1 开发代码；历史实验版本分别保留，不把后续代码核对当成重做实验。新增范围不改变上述技术笔记的决定，临时目录提案仍未全面实施，普通 tmp 后代的策略资格不能写成推荐或全面禁止。

证据在原有来源外补读合订归档的 S026 隐藏 tmp 子目录与 S063 运行时边界，以及项目历史档案 apfs-wechat-validation-2026-10-13.md、apfs-cross-app-validation-2026-10-14.md。144 条结构探针使用两个128MB本机APFS映像，其中 136 条断言匹配，另 8 条入口观察，不覆盖真实可移动卷TCC；25 个临时子目录副本使用隔离映像，不是企业微信真实清理或生产迁移器验收。第二篇保留映像的便签访问优势与空间回收样本，同时删除旧报告“速度证明未落盘”“原生只丢尾事务”“映像整卷报废”等超出证据的概括。后续物理盘 newfs 权限失败、系统建卷/noowners 修正和真实应用往返按各自范围叙述，最后原入口界面未确认之处不补写为成功。微信 build26 清理失败与 build27 往返、Maccy2.7.1和包含 build30补测的后续轮次分别标注，不能借历史结果声称固定代码已重做实机验收。

公开引用只使用博客对应实验章节、Apple 说明、公开问题和固定版本源码；不链接原始私有档案，不复制真实账户、挂载卷名、机器签名标识、聊天或诊断日志。博客没有对应译文时按现有规则回语言首页，不指向同名但不存在的线上文章。

### 路由与生成契约

保留沿用文章的 URL。17 个合并源文件退出正文与搜索（包括新增合并的六篇研究），旧 URL 通过 config/legacy-links.json 映射至当前主题或相关历史页，包含原自动标题 ID 和显式 ID。正文的固定章节 ID 转换为 Fumadocs 原生 [#id]，由实际标题持有。旧章节 ID 作为不可见锚点插入对应新章节前；同名 ID 若属于不同目标则构建报错，不能静默跳过。更新日志重复的“改进”等章节按版本固定 ID 并逐项映射，检查验证旧锚点后紧接的具体标题。

六篇旧实验的现有固定章节与更早自动章节一起展平到最终博客章节；旧 routes 引用旧实验时也改为直接目标，避免二次跳转丢失主题。

合并页 /docs/<旧路径> 参与 Next 静态参数生成，显示 noindex/canonical 并由客户端 router.replace 转到实际文章，保留查询参数并映射旧 hash。根目录的旧 .html 文件使用同一个解析函数生成跳转脚本。没有 JavaScript 时仍提供目标文章链接。本地 serve 预览对 .html 禁用自动去扩展名跳转，避免服务器先丢掉查询参数；根首页和无扩展名页面仍可访问。未知或损坏 hash 回退到该旧页的主目标，不制造无效章节。

导航描述同时约束来源清单，并用于 source.pageTree 的结构转换，侧栏、分类与上一页／下一页使用同一棵树。辅助页可被搜索和直接打开，但不改变主目录顺序；历史文章的标题和正文显式标记归档。

七种其他语言的187个源文件保持原字节内容。语言按钮优先打开线上同路径译文；新拆分主题通过 config/language-links.json 关联旧译文及现有显式章节，如经典模式到 settings#classic-data-migration-mode。无同路径或相关译文时才回语言首页。Markdown导出保留表格、提示与流程图源码，去掉仅供网页兼容的锚点标签。

## Alternatives considered

- 只把现有技术页移到“原理”：迁移成本最低且保留全部材料，但不能解决操作与原理混写、版本错误、术语重复和实验叙事过长，因此不足以满足本次目标。
- 把所有技术内容压成一篇原理长文：顶层入口最少，但应用迁移、数据迁移、徽章和经典模式的阅读任务不同，会重新形成难检索的长文；采用一个一级组和五篇短文章；完整实验推导由博客承载。
- 操作和实验全部混排在同一组：相关内容看似集中，但普通用户难区分建议操作、历史实验和验证局限；使用独立博客组承载实验并通过链接关联。
- 将两篇研究长文直接扩入短篇操作或实验：可以少一个入口，但会恢复用户刚要求降低的正文深度。博客承载单轮实验细节与跨实验的完整论证，索引提供六主题直达链接；索引和文章沿用现有文档布局，避免为三页引入另一个发布系统。
- 一次重写八种语言并重命名全部路径：结构最一致，但会扩大翻译、链接兼容和主分支协作范围；本次中文先行，稳定 URL 尽量沿用，译文切换保留线上方式。
