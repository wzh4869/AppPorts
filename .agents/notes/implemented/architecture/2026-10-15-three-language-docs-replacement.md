# Agent Note: 三语文档站独立替代旧站

Status: implemented

## Problem

中文 Fumadocs 预览与线上八语旧站并存，语言入口仍依赖旧站，旧路径映射增加维护成本。维护者已批准保留简体中文、繁体中文、英文，退出日、韩、德、法、西五语，并明确不保留旧地址兼容。

## Decision

三语各维护同一目录的 27 篇正文，包含两篇完整博客、四篇历史归档、隐私政策、许可及贡献者说明。译文保存为 Markdown，固定章节 ID、版本和实验边界与中文一致。繁体正文使用转换作为初稿后校对术语；英文按现有中文正文翻译，不能用旧译文冒充更新完成。

保留当前中文 /docs/<slug> 与首页 /；繁体和英文分别使用 /zh-Hant/docs/<slug>、/en/docs/<slug> 与各自首页。三语使用同一套 Fumadocs 组件，服务端输出对应 HTML lang、标题、导航与正文，搜索按当前语言隔离。语言切换进入同篇文章并保留共用固定章节，完全使用站内链接。缺译、章节或链接不一致在构建检查中失败，禁止静默回落到中文。

删除旧 VitePress 配置、主题、已跟踪缓存、旧首页源文件、退出语言及不再使用的旧译文。删除 .html 跳转导出、合并页路由、旧锚点别名和线上语言映射；不产生旧站重定向。保留正文现行固定章节，sponsors.json、latest.json、logo.png 等应用与站点资源继续按既有根路径输出。更新本地开发、静态主机部署说明与检查命令；本轮完成可部署产物，不自行发布线上站点或改主工作区。

## Routing and export contracts

`app/(default)` 与 `app/(localized)/[lang]` 使用两组根布局，共用 `SiteDocument` 与页面组件，在静态构建时输出对应语言的 HTML 文档，不靠客户端改写 `lang` 或需要服务器的中间件。Fumadocs source 禁用语言回退。三语搜索共用导出文件，但每次检索使用当前 locale 对应的索引。

固定章节 ID 同时服务页内导航、搜索与语言切换。生成 MDX 时保留未转义的 Fumadocs `[#id]` 标记，避免结构化搜索标题残留反斜杠。语言菜单在打开时读取当前 hash，并监听 hashchange，把章节放进真实 href，保留复制链接、Cmd 点击和新标签导航语义。

部署使用完整 `out` 静态产物，站点按路径读取对应文件；不存在的路径返回 404，不使用首页兜底。替换部署文件集时删除旧文件，避免退出页面仍由旧托管文件提供。

## Existing note audit

- [中文 Fumadocs 预览](../../implemented/architecture/2026-10-15-fumadocs-local-preview.md)：部分替代；框架、共享 Header、Markdown 导出、静态部署取舍继续成立。本篇替代中文专用构建、保留旧站和线上语言跳转的决定，互链保留原理由。
- [读者导向的结构](../../implemented/architecture/2026-10-15-reader-first-docs-structure.md)：部分替代；目录和实验事实保留，本篇替代七语原字节不变及旧地址兼容决定，互链。
- 其他迁移与签名笔记是产品事实依据，不受本次站点与翻译范围影响，无需归档。

## Alternatives considered

- 继续维护八语：覆盖更多读者，但每次变化需要维护 216 篇文章；用户选择三语的 81 篇以降低长期维护成本。
- 退出语言跳转到英文、保留旧站别名：能延续历史入口，但用户明确决定不再依赖旧站，放弃兼容层。
- 只翻译正文而继续使用中文界面或线上译文：实施量较少，但语言体验不完整且不能独立替代旧站，因此不采用。

## Verification

- 三语各 27 篇正文、26 个侧栏条目；`docs:prepare` 比较全部源文件清单和章节顺序。两篇博客的数字、失败与验证边界经独立正文审查，繁体语境转换误译已修正。
- 浏览器实测三语主页、简介、设置、博客和赞助页，在 1440、390、320 像素宽度无页面横向溢出；主题、手机目录、复制 Markdown、打开菜单与搜索可用。三语语言菜单只有站内三项，带章节的 Cmd 点击保留当前页并在新标签打开对应章节。
- 11 个旧地址样本（退出语言、根 `.html` 与退役文章）通过无重定向 HTTP 404 检查。JSON 与 logo 输出逐字节或结构匹配源数据。
- `docs:build`、`docs:typecheck`、`docs:check` 通过；静态检查覆盖 81 篇文章和 3 个首页的内部链接、锚点、canonical/hreflang、Markdown 导出与导航。Release `xcodebuild clean build` 通过。与检查时最新 main `c93e41d` 的 `git merge-tree --write-tree` 模拟合并无冲突，文档分支与主工作区未提交文件没有重叠；主工作区内容不作修改。

## Consequences

退出语言和旧站地址不再可访问是本次明确范围。旧版应用内的硬编码帮助地址也可能因此失效，后续应用发版需要采用新文档路径。人工英文翻译需要核对技术术语、数字和否定边界；繁体转换不能替代界面用词校对。新内容发布到正式域名前，GitHub 原文链接以合并后的 main 为准。

三语完整正文可独立部署，语言维护面从八语收敛到三语；减少了旧站配置和地址映射，但每次内容修改仍需同步 81 篇中的对应三份正文与共用章节。以后若有持续的其他语言维护者和实际读者需求，可重新评估语言范围。

公开贡献入口中的验证责任与同步要求见[贡献流程入口](../process/2026-10-25-contributor-workflow-entrypoints.md)；本篇原有决定保持适用。
