# 設定

AppPorts 的設定頁面可透過主視窗右上角的齒輪圖示取用。

## App Store 與 iOS 設定 <a href="#app-store-與-ios-設定" id="app-store-與-ios-設定"></a>

| 設定項 | 說明 | 預設值 |
|--------|------|--------|
| 允許遷移 Mac App Store 應用程式 | 允許遷移 App Store 應用程式。macOS 15.1 以下版本如需遷移此類應用程式，需要手動開啟 | 關閉 |
| 允許遷移非原生應用程式 | 允許遷移 iOS/iPadOS 應用程式（Mac 版） | 關閉 |

{% hint style="success" %}
**macOS 15.1+ 使用者**

macOS 15.1 及以上版本支援 App Store 應用程式原生安裝到外接儲存裝置。建議優先在 App Store 設定中開啟「下載並安裝大型 App 到獨立磁碟」，而不是使用 AppPorts 的手動遷移開關。
{% endhint %}

## 簽名設定 <a href="#簽名設定" id="簽名設定"></a>

| 設定項 | 位置 | 說明 | 預設值 |
|--------|------|------|--------|
| 遷移后重签名 | 資料目錄頁頂部工具列，**僅經典模式下顯示** | 符號連結遷移完成後對關聯應用程式執行 Ad-hoc 重簽名 | 關閉 |
| 開機自動重簽名 | 設定頁 | 登入時對簽名備份裡原本就是 Ad-hoc 的應用程式重簽名一次，處理系統重啟後簽名失效；沙盒應用程式跳過（經典模式下不跳過） | 新安裝關閉；已裝過登入代理的既有使用者保持開啟 |

非經典模式下，沙盒應用程式在所有入口都不會被重簽名：沙盒應用程式被重簽名後在 macOS 27 上可能無法開啟。容器資料的遷移改用[掛載遷移](datamigrae/mount-migration.md)，不需要動簽名。

有完整原始應用程式備份的新記錄不會被開機指令碼再次重簽名；簽名操作由 AppPorts 驗證並安全替換。應用程式啟動時會同步已安裝指令碼。

「開機自動重簽名」安裝的是 LaunchAgent `com.shimoko.AppPorts.re-sign`，日誌寫入 AppPorts 預設日誌檔案。重簽名和備份都作用於外接磁碟上的真實應用程式，不是本機啟動殼。詳見[重簽名與當機防護](datamigrae/resign.md)。

## 經典資料遷移模式（不建議） <a href="#classic-data-migration-mode" id="classic-data-migration-mode"></a>

設定頁底部的開關，預設關閉。它只為已經依賴 1.8.1 舊方式、暫時不能切換的使用者保留。外接磁碟不是 APFS 時，建議維持現狀（容器資料留在本機），而不是為了繞開 APFS 要求開啟它，見[為什麼外接磁碟必須是 APFS](why-apfs.md#what-to-do)。開啟前必須在確認對話框中勾選「我已了解上述風險」；在 macOS 27 上開關旁會提示被重簽名的沙盒應用程式可能無法開啟。開啟後：

| 項目 | 關閉（預設） | 開啟 |
|------|--------------|------|
| 容器目錄的按鈕 | 只有「掛載遷移」 | 「遷移」（符號連結）和「掛載遷移」並列 |
| 容器遷移前的重簽名對話框 | 不出現 | 出現，預設「僅遷移」 |
| 對沙盒應用程式重簽名 | 所有入口拒絕 | 允許，每次帶後果說明的二次確認 |
| 「遷移后重签名」開關 | 不顯示 | 出現在資料目錄頁工具列 |
| 容器目錄的「整理」「接回」「連結詳情」 | 禁用，提示先還原再掛載遷移 | 可用 |

經典模式等於完整恢復舊方案，包括它的風險：重簽名過的沙盒應用程式在 macOS 27 上可能無法開啟，屆時需要還原資料並重新安裝。AppPorts 會給這些應用程式打上「簽名已替換」標記，並在啟動時提醒，見 [macOS 27 升級說明](macos-27.md)。關閉經典模式不會動已有的符號連結遷移項，「還原」照常可用。

## 掛載遷移相關 <a href="#掛載遷移相關" id="掛載遷移相關"></a>

掛載遷移沒有單獨的設定項。設定頁的「準備狀況」會檢查完整磁碟取用權限、AppPorts 的安裝位置和外接儲存裝置格式，並說明哪一項需要處理。第一次掛載遷移成功時，AppPorts 會安裝登入代理 `com.shimoko.AppPorts.container-mount`，登入後自動把線上的卷宗掛回容器目錄；最後一條掛載記錄還原後自動移除。macOS 12 等舊系統上代理無法彈管理者密碼對話框，登入後需開啟 AppPorts 完成重掛。

## 日誌設定 <a href="#日誌設定" id="日誌設定"></a>

| 設定項 | 說明 | 預設值 |
|--------|------|--------|
| 啟用日誌記錄 | 將執行日誌寫入檔案 | 開啟 |
| 最大日誌大小 | 日誌檔案超出限制後，自動截斷較舊的一半內容 | 2 MB |
| 日誌位置 | 日誌檔案儲存路徑 | `~/Library/Application Support/AppPorts/AppPorts_Log.txt` |

### 日誌操作 <a href="#日誌操作" id="日誌操作"></a>

| 操作 | 說明 |
|------|------|
| 在 Finder 中查看 | 開啟日誌檔案所在目錄 |
| 匯出診斷包 | 產生包含日誌、操作記錄和系統資訊的 ZIP 檔案 |
| 清空日誌 | 清除目前日誌檔案內容 |

日誌詳細說明請參閱[日誌與診斷](logging.md)。

手動備份、重簽名或恢復前，AppPorts 會停止本次登入的背景重簽名任務並等待其子行程退出，避免背景覆蓋剛恢復的簽名。登入代理設定保留，下次登入仍按開關設定執行；無法確認背景任務已停止時，本次手動操作會中止。
