# 相容性與限制

## 系統要求 <a href="#系統要求" id="系統要求"></a>

| 要求 | 說明 |
|------|------|
| 最低系統版本 | macOS 12.0 (Monterey) |
| 架構 | Intel x86_64 / Apple Silicon (arm64) |
| 權限 | 完整磁碟取用權限 |
| 外接儲存裝置 | 需要至少一個外接儲存裝置 |

## 功能相容性 <a href="#功能相容性" id="功能相容性"></a>

### 按 macOS 版本 <a href="#按-macos-版本" id="按-macos-版本"></a>

| 功能 | macOS 12.0 - 15.0 | macOS 15.1+ |
|------|:---:|:---:|
| 應用程式遷移（Stub Portal） | ✓ | ✓ |
| 資料目錄遷移（符號連結） | ✓ | ✓ |
| 容器資料掛載遷移 | ✓（掛載需輸入管理者密碼） | ✓（27 實測無需密碼；13 至 26 未逐一驗證） |
| 目錄遷移（自訂資料夾） | ✓ | ✓ |
| 程式碼簽名管理 | ✓ | ✓ |
| App Store 應用程式遷移到外接儲存裝置 | ✗ | ✓ |
| App Store 應用程式在外接儲存裝置原地更新 | ✗ | ✓ |
| iOS 應用程式遷移 | ✓ | ✓ |

{% hint style="warning" %}
**macOS 15.1 以下的 App Store 應用程式**

macOS 15.1（Sequoia）之前的系統不支援 App Store 應用程式原生安裝到外接儲存裝置。若確需遷移，需要在 AppPorts 設定中手動開啟「允許遷移 Mac App Store 應用程式」開關；應用程式更新後，也需要再次手動遷移以覆蓋外部副本。
{% endhint %}

### 按應用程式類型 <a href="#按應用程式類型" id="按應用程式類型"></a>

| 應用程式類型 | 遷移 | 還原 | 自動更新 | 說明 |
|----------|:---:|:---:|:---:|------|
| 原生 macOS 應用程式 | ✓ | ✓ | ✓ | 最佳相容性 |
| Sparkle 應用程式 | ✓ | ✓ | 需鎖定 | 鎖定後會阻止應用程式內更新，需遷回本機後更新 |
| Electron 應用程式 | ✓ | ✓ | 需鎖定 | 與 Sparkle 應用程式相同 |
| Chrome / Edge（自訂更新器） | ✓ | ✓ | ✓ | 更新程式安裝到本機，不破壞外部副本 |
| App Store 應用程式（macOS 15.1+） | ✓ | ✓ | ✓ | 原生外接安裝，App Store 可直接更新 |
| App Store 應用程式（macOS <15.1） | ✓ | ✓ | 需手動 | 更新後需再次遷移 |
| iOS 應用程式（Mac 版） | ✓ | ✓ | ✓ | 使用 iOS Stub Portal |
| 系統應用程式 | ✗ | — | — | SIP 保護，不可遷移 |

{% hint style="warning" %}
**受保護應用程式遷移**

App Store 應用程式或 root 所有的應用程式可能因 macOS 權限無法由 AppPorts 自動刪除或替換本機副本。出現受保護應用程式提示時，建議先在 Finder 中手動移動到外接儲存裝置，再回到 AppPorts 建立本機連結。
{% endhint %}

{% hint style="success" %}
**關於 Finder 捷徑箭頭**

舊版 AppPorts 建立的遷移入口可能使用整體符號連結，因此 Finder 會顯示捷徑箭頭。目前版本對一般 `.app` 應用程式預設使用 Stub Portal，本機入口通常不會顯示箭頭；如仍看到箭頭，建議遷回本機後重新遷移。
{% endhint %}

{% hint style="success" %}
**關於「待遷出」**

「待遷出」依賴可比較的應用程式版本和可靠的同一應用程式判斷。AppPorts 會優先使用 Bundle ID 比對本機與外部應用程式，並在必要時以正規化應用程式名稱補充比對；如果版本號缺失、格式無法比較，或同名應用程式 Bundle ID 不一致，就不會顯示該狀態。
{% endhint %}

### 按資料目錄類型 <a href="#按資料目錄類型" id="按資料目錄類型"></a>

| 資料目錄類型 | 遷移方式 | 風險 |
|-------------|:---:|------|
| `~/Library/Application Support/` | 符號連結 | 中 — 應用程式可能使用檔案鎖或 SQLite WAL 日誌 |
| `~/Library/Preferences/` | 符號連結 | 低-中 — `cfprefsd` 快取可能導致讀取到過期設定 |
| `~/Library/Containers/` | 掛載 | 中 — 需要未加密的 APFS 外接磁碟；首次開啟應用程式時，需在授權對話框中允許存取；開啟前先連接磁碟 |
| `~/Library/Group Containers/` | 掛載 | 中 — 同上；共享資料會影響同一 Team 下的其他應用程式 |
| `~/Library/Caches/` | 符號連結 | 低 — 快取可重建 |
| `~/Library/Logs/` | 符號連結 | 低 — 僅日誌檔案 |
| `~/Library/WebKit/` | 符號連結 | 中 — WebKit 本機儲存 |
| `~/Library/HTTPStorages/` | 符號連結 | 低 — 網路工作階段儲存 |
| `~/Library/Application Scripts/` | 符號連結 | 低 — 延伸功能指令碼 |
| `~/Library/Saved Application State/` | 符號連結 | 低 — 視窗狀態恢復 |
| `~/.npm`、`~/.m2` 等 dot-folder | 符號連結 | 低 — 開發工具快取 |
| 使用者主目錄下的自訂資料夾 | 符號連結 | 視內容而定 — 遷移前應關閉正在寫入的應用程式或工具 |

{% hint style="warning" %}
**高價值資料目錄**

微信聊天記錄、虛擬機器映像檔、遊戲庫、資料庫、模型快取等目錄通常體積大、寫入頻繁，且對路徑和檔案鎖較敏感。遷移前建議先做獨立備份；遷移後如應用程式提示資料異常，應優先恢復到本機再排查。
{% endhint %}

{% hint style="warning" %}
**容器資料只能掛載遷移**

`~/Library/Containers/` 與 `~/Library/Group Containers/` 裡的資料用符號連結搬走後沙盒應用程式讀不到；舊版本靠重簽名繞過，代價是應用程式在 macOS 27 上可能無法開啟。1.9.0 起這兩類目錄只提供[掛載遷移](datamigrae/mount-migration.md)，並對沙盒應用程式一律拒絕重簽名。來龍去脈見[容器資料、沙盒與簽名身分](datamigrae/container-identity.md)。
{% endhint %}

{% hint style="warning" %}
**自訂目錄範圍**

目錄遷移面向使用者主目錄中的真實資料夾；不能選擇檔案、符號連結、外部目標內部路徑、系統目錄，或與已管理項目互相包含的路徑。
{% endhint %}

{% hint style="warning" %}
**目標目錄衝突**

資料目錄遷移不會因為外部目錄大小接近就自動接管或恢復。只有外部目錄中的 AppPorts metadata 與目前任務完全一致時，AppPorts 才會繼續自動恢復；否則會將其視為真實目錄衝突並停止操作。
{% endhint %}

## 不可遷移的內容 <a href="#不可遷移的內容" id="不可遷移的內容"></a>

### 受 SIP 保護 <a href="#受-sip-保護" id="受-sip-保護"></a>

| 路徑 | 原因 |
|------|------|
| macOS 系統應用程式（Safari、Finder 等） | 系統完整性保護 |
| `~/Library/Containers/` 頂層目錄 | macOS 系統保護 |

### 包含路徑引用 <a href="#包含路徑引用" id="包含路徑引用"></a>

| 路徑 | 原因 |
|------|------|
| `~/.local` | 包含可執行檔案路徑引用，遷移後命令列工具可能失效 |
| `~/.config` | 包含絕對路徑設定，遷移後工具設定可能失效 |

## 外接儲存裝置要求 <a href="#外接儲存裝置要求" id="外接儲存裝置要求"></a>

| 要求 | 說明 |
|------|------|
| 檔案系統 | 應用程式本體和一般資料目錄：APFS、HFS+、exFAT 均可。**容器資料：僅 APFS** |
| 最小空間 | 視遷移應用程式大小而定 |
| 介面 | USB、Thunderbolt、NVMe 均支援 |
| 保持連接 | 遷移後外接儲存裝置需保持連接，否則相關應用程式無法啟動 |

{% hint style="success" %}
**檔案系統建議**

- **APFS**：建議。唯一支援容器資料掛載遷移的格式，效能也最好
- **HFS+**：相容舊款 Mac，不能遷移容器資料
- **exFAT**：跨平台，不能遷移容器資料；要和 Windows 共用時可以使用獨立的 APFS 分割區。若 exFAT 佔滿整個磁碟，系統內建工具不能直接縮小它，需先備份再重新分割區；已有未配置空間時可按[分割區條件](why-apfs.md#prepare-apfs)建立 APFS 分割區

為什麼容器資料只能用 APFS，以及我們試過的替代方案，見[為什麼外接磁碟必須是 APFS](why-apfs.md)。
{% endhint %}

### 網路掛載磁碟 <a href="#網路掛載磁碟" id="網路掛載磁碟"></a>

NAS、SMB、rclone、SFTP 等網路掛載磁碟不屬於 AppPorts 的主要驗證目標。它們可能可以使用，但需要自行確認掛載穩定性、路徑一致性、權限、延伸屬性和符號連結行為。對於需要持續寫入的資料目錄，不建議優先使用網路掛載磁碟。
