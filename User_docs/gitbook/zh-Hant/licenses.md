# 開源授權

AppPorts 的實作離不開這些優秀的開源專案，在此向每一位作者與貢獻者致謝。

## 本專案 <a href="#本專案" id="本專案"></a>

- **AppPorts** — Apache License 2.0 — [檢視](<https://github.com/wzh4869/AppPorts/blob/main/LICENSE>)

## 參考與使用的第三方專案 <a href="#參考與使用的第三方專案" id="參考與使用的第三方專案"></a>

- **Pearcleaner** — Apache-2.0 with Commons Clause — 目錄體積掃描等實作參考，授權附帶 Commons Clause 條件 — [檢視](<https://github.com/alienator88/Pearcleaner>)

## 文件站使用的開源專案 <a href="#文件站使用的開源專案" id="文件站使用的開源專案"></a>

- **VitePress** — MIT — 文件站框架，隨套件分發 Inter 字型 — [檢視](<https://github.com/vuejs/vitepress>)
- **Vue.js** — MIT — 前端框架 — [檢視](<https://github.com/vuejs/core>)
- **vitepress-theme-teek** — MIT — 站點主題與圖示字型 — [檢視](<https://github.com/Kele-Bingtang/vitepress-theme-teek>)
- **Sass** — MIT — 僅建置期使用，不隨站點分發 — [檢視](<https://github.com/sass/dart-sass>)
- **Inter** — SIL OFL 1.1 — 文件站正文字型，由 VitePress 提供 — [檢視](<https://github.com/rsms/inter>)

## 圖示與字型 <a href="#圖示與字型" id="圖示與字型"></a>

- **AppPorts** — Apache-2.0 — 專案自製的應用程式圖示
- **SF Symbols** — Apple — 應用程式內圖示，由 macOS 提供，遵循 Apple 的 SF Symbols 使用條款
- **Inter** — SIL OFL 1.1 — 文件站正文字型
- **teek iconfont** — MIT — 文件站圖示字型，隨主題分發

### Pearcleaner 的附加條件 <a href="#pearcleaner-的附加條件" id="pearcleaner-的附加條件"></a>

Pearcleaner 以 Apache 2.0 with Commons Clause 發布，這是原始碼可見的 fair-code 授權，並非 OSI 認可的開源授權。除 Apache 2.0 條款外，它還禁止「銷售」以該軟體功能為主要價值的產品或服務。使用時需一併保留授權全文，其中包括：

```text
Software: Pearcleaner
License: Apache 2.0 with Commons Clause
Licensor: alienator88
```
