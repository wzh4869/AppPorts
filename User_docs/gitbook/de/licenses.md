### Zusatzbedingung bei Pearcleaner <a href="#zusatzbedingung-bei-pearcleaner" id="zusatzbedingung-bei-pearcleaner"></a>

Pearcleaner steht unter Apache 2.0 with Commons Clause – einer quelloffenen „Fair-Code"-Lizenz, die keine von der OSI anerkannte Open-Source-Lizenz ist. Zusätzlich zu den Apache-2.0-Bedingungen verbietet sie den „Verkauf" eines Produkts oder Dienstes, dessen Wert wesentlich auf dieser Software beruht. Der vollständige Lizenztext muss erhalten bleiben, einschließlich:

```text
Software: Pearcleaner
License: Apache 2.0 with Commons Clause
Licensor: alienator88
```
