# Apoyar AppPorts

AppPorts es totalmente gratuito, de código abierto y sin publicidad, y no incluye ninguna promoción comercial. Lo mantiene una sola persona en su tiempo libre y no genera ningún ingreso.

Si AppPorts te ha liberado decenas de GB, puedes invitar al autor a un café escaneando el código QR de abajo: **cualquier importe vale, incluso el más pequeño cuenta**. Tu apoyo mantiene vivo el proyecto.

## Escanea el código QR <a href="#escanea-el-codigo-qr" id="escanea-el-codigo-qr"></a>

Escanea el código con WeChat para apoyar el proyecto. **No hay importe mínimo**: da lo que te parezca bien.

## Apodo y enlace en el mensaje <a href="#apodo-y-enlace-en-el-mensaje" id="apodo-y-enlace-en-el-mensaje"></a>

Al apoyar, escribe tu **apodo** en el mensaje. El **enlace es opcional**: un perfil de GitHub, blog o red social, lo que prefieras.

El apodo y el enlace aparecerán en la lista de arriba y también en la página «Acerca de AppPorts».

{% hint style="success" %}
**¿Prefieres el anonimato?**

Sin apodo, no mostramos información sobre el apoyo. Si proporcionas un apodo sin enlace, lo mostramos como texto sin enlace.
{% endhint %}

## Orden de aparición <a href="#orden-de-aparicion" id="orden-de-aparicion"></a>

Los patrocinadores se ordenan así:

| Prioridad | Criterio |
| --- | --- |
| 1 | Importe mayor primero |
| 2 | A igual importe, el apoyo más antiguo primero |

{% hint style="success" %}
**Sin importe mínimo**

No hay importe mínimo y la cantidad no cambia nada: todas las funciones de AppPorts siguen siendo gratuitas para todo el mundo.
{% endhint %}
