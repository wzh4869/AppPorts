### Additional condition in Pearcleaner <a href="#additional-condition-in-pearcleaner" id="additional-condition-in-pearcleaner"></a>

Pearcleaner is released under Apache 2.0 with Commons Clause — a source-available "fair-code" license that is not an OSI-approved open source license. On top of the Apache 2.0 terms it forbids “Selling” a product or service whose value derives substantially from the software. Keep the full license text, which includes:

```text

License: Apache 2.0 with Commons Clause
Licensor: alienator88
```
