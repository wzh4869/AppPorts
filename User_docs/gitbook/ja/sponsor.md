# AppPorts をスポンサーする

AppPorts は完全無料・オープンソース・広告なしで、商業的なプロモーションも一切ありません。個人が余暇に維持しているプロジェクトで、商業的な収入はありません。

AppPorts でローカル容量を数十 GB 節約できた方は、下の QR コードから作者にコーヒーを奢ってあげてください。**金額は自由、ほんの気持ちでも大きな励みになります。** 皆さまの支援が開発を続ける力になります。

WeChat で読み取ってスポンサーできます。**最低金額はありません**ので、無理のない範囲でお願いします。

## メッセージのお願い <a href="#メッセージのお願い" id="メッセージのお願い"></a>

スポンサーの際は、メッセージ（備考）に**ニックネーム**をご記入ください。**リンクは任意**です。GitHub、ブログ、SNS など、どこでも構いません。

いただいた「ニックネーム + リンク」は、上のリストと AppPorts の「AppPortsについて」ページに掲載させていただきます。

{% hint style="success" %}
**公開したくない場合**

ニックネームがない場合は情報を掲載しません。ニックネームのみの場合は、リンクなしの文字として掲載します。
{% endhint %}

## 掲載順 <a href="#掲載順" id="掲載順"></a>

スポンサーは次の順で並びます。

| 優先度 | 並び順 |
| --- | --- |
| 1 | スポンサー金額の高い順 |
| 2 | 同額の場合はスポンサー日時の早い順 |

{% hint style="success" %}
**金額の下限はありません**

金額に下限はなく、AppPorts のすべての機能はどなたでも無料でご利用いただけます。
{% endhint %}
