# 互換性と制限

## システム要件 <a href="#システム要件" id="システム要件"></a>

| 要件 | 説明 |
|------|------|
| 最低 OS バージョン | macOS 12.0 (Monterey) |
| アーキテクチャ | Intel x86_64 / Apple Silicon (arm64) |
| アクセス権 | フルディスクアクセス |
| 外部ストレージ | 1 台以上の外部ストレージが必要 |

## 機能の互換性 <a href="#機能の互換性" id="機能の互換性"></a>

### macOS のバージョン別 <a href="#macos-のバージョン別" id="macos-のバージョン別"></a>

| 機能 | macOS 12.0 - 15.0 | macOS 15.1+ |
|------|:---:|:---:|
| アプリの移行（Stub Portal） | ✓ | ✓ |
| データディレクトリの移行（シンボリックリンク） | ✓ | ✓ |
| コンテナデータのマウント移行 | ✓（マウントに管理者パスワードが必要） | ✓（27 は実測でパスワード不要。13〜26 は個別に未検証） |
| ディレクトリの移行（カスタムフォルダ） | ✓ | ✓ |
| コード署名の管理 | ✓ | ✓ |
| App Store アプリの外部ストレージへの移行 | ✗ | ✓ |
| App Store アプリの外部ストレージ上での直接更新 | ✗ | ✓ |
| iOS アプリの移行 | ✓ | ✓ |

{% hint style="warning" %}
**macOS 15.1 より前の App Store アプリ**

macOS 15.1（Sequoia）より前は、App Store アプリの外部ストレージへの直接インストールに対応していません。移行が必要な場合は、AppPorts の設定で「Mac App Storeアプリの移行を許可」を手動で有効にしてください。アプリの更新後も手動で再移行し、外部のコピーを置き換える必要があります。
{% endhint %}

### アプリ種別 <a href="#アプリ種別" id="アプリ種別"></a>

| アプリ種別 | 移行 | 復元 | 自動更新 | 説明 |
|----------|:---:|:---:|:---:|------|
| ネイティブ macOS アプリ | ✓ | ✓ | ✓ | 最も高い互換性 |
| Sparkle アプリ | ✓ | ✓ | ロックが必要 | ロックするとアプリ内更新がブロックされるため、ローカルに戻して更新 |
| Electron アプリ | ✓ | ✓ | ロックが必要 | Sparkle アプリと同様 |
| Chrome / Edge（独自の更新プログラム） | ✓ | ✓ | ✓ | 更新はローカルにインストールされ、外部のコピーを壊さない |
| App Store アプリ（macOS 15.1+） | ✓ | ✓ | ✓ | 外部への直接インストールに対応し、App Store がその場で更新可能 |
| App Store アプリ（macOS <15.1） | ✓ | ✓ | 手動 | 更新後に再移行が必要 |
| iOS アプリ（Mac 版） | ✓ | ✓ | ✓ | iOS Stub Portal を使用 |
| システムアプリ | ✗ | — | — | SIP によって保護され、移行不可 |

{% hint style="warning" %}
**保護されたアプリの移行**

App Store アプリや root が所有するアプリは、macOS のアクセス権により、AppPorts がローカルのコピーを自動で削除または置換できない場合があります。保護されたアプリの案内が出たら、Finder で外部ストレージへ手動で移し、AppPorts に戻ってローカルのリンクを作成することをお勧めします。
{% endhint %}

{% hint style="success" %}
**Finder のショートカット矢印について**

旧版の AppPorts はアプリ全体へのシンボリックリンクを作成する場合があるため、Finder に矢印が表示されます。現在のバージョンは通常の `.app` にデフォルトで Stub Portal を使い、通常はローカルの起動用エントリに矢印が表示されません。残っている場合は、ローカルに戻してから再移行してください。
{% endhint %}

{% hint style="success" %}
**「移行待ち」について**

「移行待ち」の判定には、比較可能なバージョンと、同じアプリであることの確実な照合が必要です。AppPorts は Bundle ID を優先してローカルと外部のアプリを照合し、必要に応じて正規化したアプリ名も使います。バージョンがない、形式を比較できない、または同名アプリの Bundle ID が異なる場合、この状態は表示しません。
{% endhint %}

### データディレクトリの種類別 <a href="#データディレクトリの種類別" id="データディレクトリの種類別"></a>

| データディレクトリ | 移行方法 | リスク |
|-------------|:---:|------|
| `~/Library/Application Support/` | シンボリックリンク | 中 — ファイルロックや SQLite の WAL ログを使うアプリがある |
| `~/Library/Preferences/` | シンボリックリンク | 低〜中 — `cfprefsd` のキャッシュから古い設定を読む場合がある |
| `~/Library/Containers/` | マウント | 中 — 未暗号化の APFS 外部ドライブが必要。初回起動時にアクセスを許可し、起動前にドライブを接続する |
| `~/Library/Group Containers/` | マウント | 中 — 上記と同様。共有データは同じ Team のほかのアプリにも影響する |
| `~/Library/Caches/` | シンボリックリンク | 低 — キャッシュは再作成可能 |
| `~/Library/Logs/` | シンボリックリンク | 低 — ログファイルのみ |
| `~/Library/WebKit/` | シンボリックリンク | 中 — WebKit のローカルストレージ |
| `~/Library/HTTPStorages/` | シンボリックリンク | 低 — ネットワークセッションの保存領域 |
| `~/Library/Application Scripts/` | シンボリックリンク | 低 — 機能拡張のスクリプト |
| `~/Library/Saved Application State/` | シンボリックリンク | 低 — ウィンドウの状態復元 |
| `~/.npm`、`~/.m2` などの dot-folder | シンボリックリンク | 低 — 開発ツールのキャッシュ |
| ユーザーのホーム内のカスタムフォルダ | シンボリックリンク | 内容による — 書き込み中のアプリやツールを終了してから移行する |

{% hint style="warning" %}
**重要なデータディレクトリ**

WeChat のチャット履歴、仮想マシンイメージ、ゲームライブラリ、データベース、モデルキャッシュは容量が大きく、頻繁に書き込まれ、パスやファイルロックの影響を受けやすいデータです。移行前に独立したバックアップを作成してください。移行後にデータの異常が表示された場合は、まずローカルに戻してから調査することをお勧めします。
{% endhint %}

{% hint style="warning" %}
**コンテナデータにはマウント移行を使用します**

`~/Library/Containers/` と `~/Library/Group Containers/` のデータをシンボリックリンクで移すと、サンドボックスアプリから読めなくなります。旧版は再署名で回避していましたが、macOS 27 でアプリが開けなくなる可能性があります。1.9.0 以降はこの 2 種類のディレクトリに[マウント移行](datamigrae/mount-migration.md)のみを提供し、サンドボックスアプリの再署名を一律で拒否します。[コンテナデータ、サンドボックスと署名 ID](datamigrae/container-identity.md)を参照してください。
{% endhint %}

{% hint style="warning" %}
**カスタムディレクトリの対象範囲**

ディレクトリ移行の対象は、ユーザーのホーム内にある実際のフォルダです。ファイル、シンボリックリンク、外部の移行先の内部、システムディレクトリ、管理済み項目と親子関係になるパスは選択できません。
{% endhint %}

{% hint style="warning" %}
**移行先の競合**

外部ディレクトリのサイズが近いだけで、自動的に管理対象にしたり復元したりすることはありません。外部ディレクトリの AppPorts metadata が現在の操作と完全に一致する場合だけ、自動復旧を続けます。それ以外は実際のディレクトリとの競合として停止します。
{% endhint %}

## 移行できないもの <a href="#移行できないもの" id="移行できないもの"></a>

### SIP によって保護されたもの <a href="#sip-によって保護されたもの" id="sip-によって保護されたもの"></a>

| パス | 理由 |
|------|------|
| macOS のシステムアプリ（Safari、Finder など） | システム整合性保護 |
| `~/Library/Containers/` の最上位ディレクトリ | macOS によるシステム保護 |

### パス参照を含むもの <a href="#パス参照を含むもの" id="パス参照を含むもの"></a>

| パス | 理由 |
|------|------|
| `~/.local` | 実行ファイルのパス参照を含み、移行後にコマンドラインツールが動作しなくなる可能性がある |
| `~/.config` | 絶対パスの設定を含み、移行後にツールの設定が無効になる可能性がある |

## 外部ストレージの要件 <a href="#外部ストレージの要件" id="外部ストレージの要件"></a>

| 要件 | 説明 |
|------|------|
| ファイルシステム | アプリ本体と通常のデータディレクトリは APFS、HFS+、exFAT に対応。**コンテナデータは APFS のみ** |
| 最低空き容量 | 移行するアプリのサイズによる |
| 接続方式 | USB、Thunderbolt、NVMe に対応 |
| 接続の維持 | 移行後も外部ストレージの接続が必要。未接続では該当アプリを起動できない |

{% hint style="success" %}
**ファイルシステムの推奨事項**

- **APFS**：推奨。コンテナデータのマウント移行に対応する唯一の形式で、性能も最良です。
- **HFS+**：古い Mac と互換性があります。コンテナデータは移行できません。
- **exFAT**：複数の OS で使えますが、コンテナデータは移行できません。Windows と共用する場合は、別の APFS パーティションを使えます。exFAT がドライブ全体を使用していると、標準ツールでは直接縮小できないため、バックアップしてからパーティションを作り直す必要があります。未割り当て領域があれば、[パーティションの条件](why-apfs.md#prepare-apfs)に従って APFS パーティションを追加できます。

APFS が必要な理由と検討した代替案は、[外部ドライブに APFS が必要な理由](why-apfs.md)を参照してください。
{% endhint %}

### ネットワークドライブ <a href="#ネットワークドライブ" id="ネットワークドライブ"></a>

NAS、SMB、rclone、SFTP などのネットワークドライブは、AppPorts の主な検証対象ではありません。利用できる場合もありますが、マウントの安定性、パスの一貫性、アクセス権、拡張属性、シンボリックリンクの動作を自分で確認する必要があります。継続的に書き込むデータディレクトリには、ネットワークドライブを優先して使うことは推奨しません。
