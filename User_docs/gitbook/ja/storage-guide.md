# 外部ストレージガイド

外部ストレージの安定性は、移行後のアプリ起動、データディレクトリへのアクセス、更新に直接影響します。性能が安定し、十分な容量がある外部 SSD を優先してください。

## 推奨構成 <a href="#推奨構成" id="推奨構成"></a>

| 項目 | 推奨値 | 説明 |
|--------|--------|------|
| 容量 | 256 GB 以上 | 移行するアプリとデータディレクトリの数によって必要量は異なります |
| 接続方式 | USB 3.0 以上 / Thunderbolt | USB 2.0 は遅く、大きなアプリの移行に時間がかかります |
| ファイルシステム | APFS | コンテナデータの移行に対応する唯一の形式です。クローン、スナップショット、容量の共有にも対応し、性能も最良です |

## 接続方式による性能比較 <a href="#接続方式による性能比較" id="接続方式による性能比較"></a>

| 接続方式 | 理論速度 | 実際の移行速度 | 用途 |
|------|----------|-------------|----------|
| USB 2.0 | 480 Mbps | ~30 MB/s | 大きなアプリの移行に時間がかかるため非推奨 |
| USB 3.0 (USB-A) | 5 Gbps | ~350 MB/s | 基本的な用途には十分 |
| USB 3.1 Gen 2 (USB-C) | 10 Gbps | ~700 MB/s | 推奨 |
| Thunderbolt 3/4 | 40 Gbps | ~2500 MB/s | 最良の性能 |
| NVMe (Thunderbolt) | 40 Gbps | ~2800 MB/s | 最良の性能 |

## ファイルシステムの選択 <a href="#ファイルシステムの選択" id="ファイルシステムの選択"></a>

### APFS（推奨） <a href="#apfs-推奨" id="apfs-推奨"></a>

- クローン、スナップショット、容量の共有に対応
- 性能が最良で、特に SSD に適しています
- macOS が標準対応
- **コンテナデータ（WeChat のチャット履歴など、`~/Library/Containers/` 内）の移行は APFS の外部ドライブにのみ対応します**。理由と実験は[外部ドライブに APFS が必要な理由](why-apfs.md)を参照してください

### HFS+ <a href="#hfs" id="hfs"></a>

- 互換性が高く、古い Mac に適しています
- クローンとスナップショットには非対応
- ハードディスクに適しています

### exFAT <a href="#exfat" id="exfat"></a>

- macOS と Windows で共有しやすい形式です
- ハードリンクとクローンには非対応
- 性能は比較的低めです
- 複数の OS 間でファイルを交換する用途に適しています
- コンテナデータは移行できません。Windows と併用する場合は、AppPorts 用に独立した APFS パーティションを使えます。exFAT がドライブ全体を占めている場合、標準ツールで直接縮小できないため、バックアップしてから再パーティションする必要があります。[パーティションの条件と対処方法](why-apfs.md#prepare-apfs)を参照してください

## 容量の計画 <a href="#容量の計画" id="容量の計画"></a>

移行後に使う外部ストレージ容量は、アプリとデータディレクトリのサイズによって決まります。主なアプリの目安は次のとおりです。

| アプリの種類 | サイズ |
|----------|------|
| Chrome | ~500 MB |
| Microsoft Office | ~5 GB |
| Adobe Creative Cloud | ~20-50 GB |
| Xcode | ~15 GB |
| Final Cut Pro | ~5 GB |
| ローカルの大規模言語モデル（Ollama） | ~4-30 GB |

{% hint style="success" %}
**容量の目安**

- 軽い利用（5-10 アプリ）：128 GB
- 中程度（10-20 アプリ）：256 GB
- 多い利用（20 以上のアプリとデータディレクトリ）：512 GB 以上
{% endhint %}

## 注意点 <a href="#注意点" id="注意点"></a>

- 外部ストレージは接続したままにしてください。オフラインでは移行済みのアプリやデータディレクトリを使用できません。
- 外部ストレージ上の重要なデータは定期的にバックアップしてください。
- コピーの中断や状態の不整合を防ぐため、移行中に外部ストレージを取り外さないでください。
- 取り外す前に、外部データを使うアプリを終了してください。マウント移行したディレクトリは、先に AppPorts で「マウント解除」を実行することをおすすめします。
- AppPorts の外部データディレクトリの保存先を、通常のファイルで置き換えないでください。AppPorts が再リンクや整理を行うのは実体のあるディレクトリだけです。
- 外部ストレージに問題が起きた場合は、接続を復旧してから AppPorts でアプリをローカルに戻すことを試してください。
