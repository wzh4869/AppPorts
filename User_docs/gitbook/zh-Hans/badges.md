# 状态徽章说明

AppPorts 使用胶囊形状的彩色徽章展示应用和数据目录的状态。部分徽章支持点击，可查看更详细的说明或处理建议。

## 应用状态徽章 <a href="#应用状态徽章" id="应用状态徽章"></a>

### 链接状态 <a href="#链接状态" id="链接状态"></a>

| 徽章 | 图标 | 颜色 | 含义 |
|------|------|------|------|
| 已链接 | `link` | 绿色 | 应用已迁移到外部存储，并已创建本地入口 |
| 锁定迁移 | `lock.fill` | 绿色 | 应用已链接且被 `uchg` 锁定，可防止自更新破坏外部副本 |
| 非锁定迁移 | `lock.open` | 橙色 | 应用已链接但未锁定，应用内更新可能删除或覆盖外部副本 |
| 部分链接 | `link.badge.plus` | 黄色 | 应用的部分组件已链接（如目录中的部分 `.app`） |
| 孤立链接 | `link.badge.exclamationmark` | 红色 | 外部存储上的应用已丢失，但本地入口仍存在 |
| 未链接 | `externaldrive.badge.xmark` | 橙色 | 应用位于外部存储，但尚未链接回本地 |
| 外部 | `externaldrive` | 橙色 | 外部存储上的应用，本地无入口 |
| 待迁出 | `arrow.up.right.circle` | 青色 | 本地真实应用版本高于外部存储中的同名旧副本，可迁出并替换外部旧版本 |
| 本地 | `macmini` | 次要色 | 普通本地应用，未迁移，无其他标签时显示 |

{% hint style="success" %}
**待迁出如何判断**

AppPorts 会优先按 Bundle ID 匹配本地应用与外部应用，必要时再按规范化后的应用名称兜底。只有双方版本号可比较且本地版本更高时，才会显示「待迁出」。如果版本缺失、格式无法比较，或同名应用的 Bundle ID 不一致，AppPorts 会保持普通本地状态，避免误覆盖外部应用。
{% endhint %}

### 框架标签 <a href="#框架标签" id="框架标签"></a>

| 徽章 | 图标 | 颜色 | 含义 | 点击说明 |
|------|------|------|------|----------|
| Sparkle | `arrow.triangle.2.circlepath` | 青色 | 使用 Sparkle 框架自动更新 | 迁移到外部存储后，应用内更新可能导致外部副本丢失，建议使用锁定迁移 |
| Electron | `atom` | 靛蓝 | 基于 Electron 框架，可能支持自动更新 | 迁移到外部存储后，应用内更新可能导致外部副本丢失，建议使用锁定迁移 |

### 类型标签 <a href="#类型标签" id="类型标签"></a>

| 徽章 | 图标 | 颜色 | 含义 |
|------|------|------|------|
| 运行中 | `play.fill` | 紫色 | 应用当前正在运行 |
| 系统 | `lock.fill` | 灰色 | macOS 系统应用 |
| 非原生 | `iphone` | 粉色 | iOS/iPadOS 应用（通过 Apple Silicon 运行） |
| 商店 | `applelogo` | 蓝色 | Mac App Store 应用 |

### 特殊标签 <a href="#特殊标签" id="特殊标签"></a>

| 徽章 | 图标 | 颜色 | 含义 |
|------|------|------|------|
| 已重签名 | `seal.fill` | 青色 | 应用当前是 Ad-hoc 签名，且 AppPorts 有它的签名备份 |
| 签名已替换 | `exclamationmark.shield.fill` | 红色 | AppPorts 曾用 Ad-hoc 签名替换了它的开发者签名。在 macOS 27 上可能无法打开，点击查看说明，右键「查看修复步骤」打开修复面板。见 [macOS 27 升级说明](macos-27.md) |

{% hint style="success" %}
**「已重签名」和「签名已替换」的区别**

两者都表示应用当前是 Ad-hoc 签名，区别在于**原来是什么签名**。「已重签名」的应用原本就没有开发者签名（或已无法确认），重签名只是让它能照常打开。「签名已替换」的应用原本有开发者签名，被换成了 Ad-hoc，沙盒应用在 macOS 27 上可能因此打不开，所以用红色标出并提供修复入口。
{% endhint %}

{% hint style="success" %}
**商店标签的特殊说明**

当应用满足以下条件时，「商店」标签可点击，并显示 macOS 15.1+ 原生外置安装说明：

- 应用位于外部存储的 `/Volumes/{drive}/Applications/` 目录。
- 应用由 macOS 原生管理，App Store 可直接在该目录中执行增量更新。
{% endhint %}

## 数据目录状态徽章 <a href="#数据目录状态徽章" id="数据目录状态徽章"></a>

| 状态 | 颜色 | 含义 |
|------|------|------|
| 本地 | 次要色 | 目录在本地，未迁移。容器目录旁边带一个盾牌图标，表示它用挂载迁移 |
| 已链接 | 绿色 | 符号链接迁移完成，本地是指向外置盘的链接 |
| 已挂载 | 紫色 | 挂载迁移完成，外置盘上的卷挂在原目录上 |
| 待挂载 | 橙色 | 挂载迁移的卷在线但没挂上，点「挂载」 |
| 外置盘未连接 | 红色 | 找不到挂载迁移的数据卷，多半是外置盘没连接；连上后 AppPorts 会自动接回 |
| 待规范 | 黄色 | AppPorts 管理的链接，但外部路径不在规范位置，可执行「整理」 |
| 待接回 | 橙色 | 外置盘上的数据还在，本地链接丢了，可执行「接回」 |
| 现有软链 | 蓝色 | 不是 AppPorts 建的符号链接，可选择纳入管理 |

## 应用状态组合示例 <a href="#应用状态组合示例" id="应用状态组合示例"></a>

一个应用可能同时显示多个徽章：

```text
[已链接] [Sparkle] [运行中]
```
含义：应用已迁移到外部存储，使用 Sparkle 自动更新框架，并且当前正在运行。

```text
[外部] [商店] [非原生]
```
含义：外部存储上的 iOS 应用（Mac 版），由 App Store 安装。

```text
[孤立链接]
```
含义：外部存储上的应用已丢失或被移除，但本地仍保留入口，需要手动解除链接。

```text
[待迁出]
```
含义：本地存在新版真实应用，外部存储中仍是旧副本。可重新执行迁移，将本地新版迁出并替换外部旧版本。
