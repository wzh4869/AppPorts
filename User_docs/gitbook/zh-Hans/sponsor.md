## 留言说明 <a href="#留言说明" id="留言说明"></a>

赞助时，请在留言（备注）中写下你的**昵称**；**个人链接可选**，GitHub 主页、个人博客、社交账号等都可以。

收到赞助后，我们会把「昵称 + 链接」收录，并展示在上面的名单以及 AppPorts 的「关于 AppPorts」页面中，感谢每一份支持。

{% hint style="success" %}
**不想公开也没关系**

未提供昵称时，我们不会展示赞助信息；提供昵称但没有链接时，仅展示昵称，不附带跳转链接。
{% endhint %}
