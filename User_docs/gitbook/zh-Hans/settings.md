# 设置

AppPorts 的设置页面可通过主窗口右上角的齿轮图标访问。

## App Store 与 iOS 设置 <a href="#app-store-与-ios-设置" id="app-store-与-ios-设置"></a>

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| App Store 应用迁移 | 允许迁移 App Store 应用。macOS 15.1 以下版本如需迁移此类应用，需要手动开启 | 关闭 |
| iOS 应用迁移 | 允许迁移 iOS/iPadOS 应用（Mac 版） | 关闭 |

{% hint style="success" %}
**macOS 15.1+ 用户**

macOS 15.1 及以上版本支持 App Store 应用原生安装到外部存储。建议优先在 App Store 设置中开启「下载并安装大型 App 到独立存储盘」，而不是使用 AppPorts 的手动迁移开关。
{% endhint %}

## 签名设置 <a href="#签名设置" id="签名设置"></a>

| 设置项 | 位置 | 说明 | 默认值 |
|--------|------|------|--------|
| 迁移后重签名 | 数据目录页顶部工具栏，**仅经典模式下显示** | 符号链接迁移完成后对关联应用执行 Ad-hoc 重签名 | 关闭 |
| 开机自动重签名 | 设置页 | 登录时对签名备份里原本就是 Ad-hoc 的应用重签一次，处理系统重启后签名失效；沙盒应用跳过（经典模式下不跳过） | 新安装关闭；已装过登录代理的老用户保持开启 |

非经典模式下，沙盒应用在所有入口都不会被重签名：沙盒应用被重签名后在 macOS 27 上可能无法打开。容器数据的迁移改用[挂载迁移](datamigrae/mount-migration.md)，不需要动签名。

有完整原始应用备份的新记录不会被开机脚本再次重签；签名操作由 AppPorts 校验并安全替换。应用启动时会同步已安装脚本。

「开机自动重签名」安装的是 LaunchAgent `com.shimoko.AppPorts.re-sign`，日志写入 AppPorts 默认日志文件。重签名和备份都作用于外置盘上的真实应用，不是本地启动壳。详见[重签名与崩溃防护](datamigrae/resign.md)。

## 经典数据迁移模式（不推荐） <a href="#classic-data-migration-mode" id="classic-data-migration-mode"></a>

设置页底部的开关，默认关闭。它只为已经依赖 1.8.1 老办法、暂时不能切换的用户保留。外置盘不是 APFS 时，建议保留现状（容器数据留在本机），而不是为了绕开 APFS 要求打开它，见[为什么外置盘必须是 APFS](why-apfs.md#what-to-do)。打开前必须在确认框里勾选"我已了解风险"；在 macOS 27 上开关旁会提示被重签名的沙盒应用可能无法打开。打开后：

| 项目 | 关闭（默认） | 打开 |
|------|--------------|------|
| 容器目录的按钮 | 只有「挂载迁移」 | 「迁移」（符号链接）和「挂载迁移」并列 |
| 容器迁移前的重签名弹窗 | 不出现 | 出现，默认「仅迁移」 |
| 对沙盒应用重签名 | 所有入口拒绝 | 允许，每次带后果说明的二次确认 |
| 「迁移后重签名」开关 | 不显示 | 出现在数据目录页工具栏 |
| 容器目录的「整理」「接回」「链接详情」 | 禁用，提示先还原再挂载迁移 | 可用 |

经典模式等于完整恢复旧方案，包括它的风险：重签名过的沙盒应用在 macOS 27 上可能无法打开，届时需要还原数据并重装。AppPorts 会给这些应用打上「签名已替换」标记，并在启动时提醒，见 [macOS 27 升级说明](macos-27.md)。关闭经典模式不会动已有的符号链接迁移项，「还原」照常可用。

## 挂载迁移相关 <a href="#挂载迁移相关" id="挂载迁移相关"></a>

挂载迁移没有单独的设置项。设置页的「准备情况」会检查完全磁盘访问权限、AppPorts 的安装位置和外部存储格式，并说明哪一项需要处理。第一次挂载迁移成功时，AppPorts 会安装登录代理 `com.shimoko.AppPorts.container-mount`，登录后自动把在线的卷挂回容器目录；最后一条挂载记录被还原后自动卸载。macOS 12 等旧系统上代理无法弹管理员密码框，登录后需打开 AppPorts 完成重挂。

## 日志设置 <a href="#日志设置" id="日志设置"></a>

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用日志记录 | 将运行日志写入文件 | 开启 |
| 最大日志大小 | 日志文件超出限制后，自动截断较旧的一半内容 | 2 MB |
| 日志位置 | 日志文件保存路径 | `~/Library/Application Support/AppPorts/AppPorts_Log.txt` |

### 日志操作 <a href="#日志操作" id="日志操作"></a>

| 操作 | 说明 |
|------|------|
| 在 Finder 中查看 | 打开日志文件所在目录 |
| 导出诊断包 | 生成包含日志、操作记录和系统信息的 ZIP 文件 |
| 清空日志 | 清除当前日志文件内容 |

日志详细说明请参阅[日志与诊断](logging.md)。

手动备份、重签或恢复前，AppPorts 会停止本次登录的后台重签任务并等待其子进程退出，避免后台覆盖刚恢复的签名。登录代理配置保留，下次登录仍按开关设置运行；无法确认后台任务已停止时，本次手动操作会中止。
