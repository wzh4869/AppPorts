# 开源许可

AppPorts 的实现离不开这些优秀的开源项目，在此向每一位作者与贡献者致谢。

## 本项目 <a href="#本项目" id="本项目"></a>

- **AppPorts** — Apache License 2.0 — [查看](<https://github.com/wzh4869/AppPorts/blob/main/LICENSE>)

## 参考与使用的第三方项目 <a href="#参考与使用的第三方项目" id="参考与使用的第三方项目"></a>

- **Pearcleaner** — Apache-2.0 with Commons Clause — 目录体积扫描等实现参考，许可证附带 Commons Clause 条件 — [查看](<https://github.com/alienator88/Pearcleaner>)

## 文档站使用的开源项目 <a href="#文档站使用的开源项目" id="文档站使用的开源项目"></a>

- **VitePress** — MIT — 文档站框架，随包分发 Inter 字体 — [查看](<https://github.com/vuejs/vitepress>)
- **Vue.js** — MIT — 前端框架 — [查看](<https://github.com/vuejs/core>)
- **vitepress-theme-teek** — MIT — 站点主题与图标字体 — [查看](<https://github.com/Kele-Bingtang/vitepress-theme-teek>)
- **Sass** — MIT — 仅构建期使用，不随站点分发 — [查看](<https://github.com/sass/dart-sass>)
- **Inter** — SIL OFL 1.1 — 文档站正文字体，由 VitePress 提供 — [查看](<https://github.com/rsms/inter>)

## 图标与字体 <a href="#图标与字体" id="图标与字体"></a>

- **AppPorts** — Apache-2.0 — 项目自制的应用图标
- **SF Symbols** — Apple — 应用内图标，由 macOS 提供，遵循 Apple 的 SF Symbols 使用条款
- **Inter** — SIL OFL 1.1 — 文档站正文字体
- **teek iconfont** — MIT — 文档站图标字体，随主题分发

### Pearcleaner 的附加条件 <a href="#pearcleaner-的附加条件" id="pearcleaner-的附加条件"></a>

Pearcleaner 以 Apache 2.0 with Commons Clause 发布，这是源码可见的 fair-code 许可，并非 OSI 认可的开源许可。除 Apache 2.0 条款外，它还禁止「销售」以该软件功能为主要价值的产品或服务。使用时需一并保留许可证全文，其中包括：

```text
Software: Pearcleaner
License: Apache 2.0 with Commons Clause
Licensor: alienator88
```
