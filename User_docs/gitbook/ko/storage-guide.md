# 외장 저장 장치 가이드

외장 저장 장치의 안정성은 마이그레이션한 앱의 실행, 데이터 디렉토리 접근과 이후 업데이트에 직접 영향을 줍니다. 성능이 안정적이고 용량이 충분한 외장 SSD를 우선 권장합니다.

## 권장 구성 <a href="#권장-구성" id="권장-구성"></a>

| 구성 항목 | 권장값 | 설명 |
|--------|--------|------|
| 용량 | 256 GB 이상 | 실제 필요 용량은 마이그레이션할 앱과 데이터 디렉토리 수에 따라 달라짐 |
| 인터페이스 | USB 3.0 이상 / Thunderbolt | USB 2.0은 느려 대용량 앱 마이그레이션에 오래 걸림 |
| 파일 시스템 | APFS | 컨테이너 데이터 마이그레이션을 지원하는 유일한 형식. 복제, 스냅샷, 공간 공유도 지원하며 성능이 가장 좋음 |

## 인터페이스 성능 비교 <a href="#인터페이스-성능-비교" id="인터페이스-성능-비교"></a>

| 인터페이스 | 이론상 속도 | 실제 마이그레이션 속도 | 적합한 용도 |
|------|----------|-------------|----------|
| USB 2.0 | 480 Mbps | ~30 MB/s | 권장하지 않음. 대용량 앱 마이그레이션에 오래 걸림 |
| USB 3.0 (USB-A) | 5 Gbps | ~350 MB/s | 기본 용도로 충분 |
| USB 3.1 Gen 2 (USB-C) | 10 Gbps | ~700 MB/s | 권장 |
| Thunderbolt 3/4 | 40 Gbps | ~2500 MB/s | 최고 성능 |
| NVMe (Thunderbolt) | 40 Gbps | ~2800 MB/s | 최고 성능 |

## 파일 시스템 권장 사항 <a href="#파일-시스템-권장-사항" id="파일-시스템-권장-사항"></a>

### APFS(권장) <a href="#apfs-권장" id="apfs-권장"></a>

- 복제, 스냅샷과 공간 공유를 지원합니다.
- 성능이 가장 좋으며 특히 SSD에 적합합니다.
- macOS가 기본으로 지원합니다.
- **WeChat 채팅 기록 등 `~/Library/Containers/`의 컨테이너 데이터 마이그레이션에는 외장 APFS 드라이브만 지원합니다.** 이유와 실험 내용은 [외장 드라이브에 APFS가 필요한 이유](why-apfs.md)를 참조하세요.

### HFS+ <a href="#hfs" id="hfs"></a>

- 호환성이 좋으며 구형 Mac에 적합합니다.
- 복제와 스냅샷을 지원하지 않습니다.
- 기계식 하드 드라이브에 적합합니다.

### exFAT <a href="#exfat" id="exfat"></a>

- 플랫폼 간 호환성이 좋아 macOS와 Windows에서 함께 사용하기에 적합합니다.
- 하드 링크와 복제를 지원하지 않습니다.
- 성능은 상대적으로 낮습니다.
- 여러 운영 체제 사이에서 파일을 주고받는 용도에 적합합니다.
- 컨테이너 데이터는 마이그레이션할 수 없습니다. Windows에서도 사용해야 한다면 AppPorts용 APFS 파티션을 별도로 둘 수 있습니다. exFAT가 드라이브 전체를 차지하면 시스템 기본 도구로 바로 축소할 수 없으므로 백업 후 다시 파티션해야 합니다. [파티션 조건과 처리 방법](why-apfs.md#prepare-apfs)을 참조하세요.

## 용량 계획 <a href="#용량-계획" id="용량-계획"></a>

AppPorts 마이그레이션 후 외장 저장 장치의 사용량은 옮긴 앱과 데이터 디렉토리 크기에 따라 달라집니다. 일반적인 앱의 참고 크기는 다음과 같습니다.

| 앱 유형 | 크기 |
|----------|------|
| Chrome | ~500 MB |
| Microsoft Office | ~5 GB |
| Adobe Creative Cloud | ~20-50 GB |
| Xcode | ~15 GB |
| Final Cut Pro | ~5 GB |
| 로컬 대규모 언어 모델(Ollama) | ~4-30 GB |

{% hint style="success" %}
**권장 용량**

- 가벼운 사용(앱 5-10개): 128 GB.
- 보통 사용(앱 10-20개): 256 GB.
- 많은 사용(앱 20개 이상 및 데이터 디렉토리): 512 GB 이상.
{% endhint %}

## 유의 사항 <a href="#유의-사항" id="유의-사항"></a>

- 외장 저장 장치를 계속 연결해야 합니다. 연결되지 않으면 마이그레이션한 앱과 데이터 디렉토리를 사용할 수 없습니다.
- 외장 저장 장치의 중요한 데이터는 정기적으로 백업하세요.
- 마이그레이션 중에는 외장 저장 장치를 분리하지 마세요. 복사가 중단되거나 상태가 일치하지 않을 수 있습니다.
- 드라이브를 분리하기 전에 외부 데이터를 사용하는 앱을 종료하세요. 마운트 마이그레이션한 디렉토리는 AppPorts에서 먼저 “마운트 해제”를 선택하는 것이 좋습니다.
- AppPorts의 외부 데이터 디렉토리 대상 경로에 일반 파일을 직접 두지 마세요. AppPorts는 실제 디렉토리만 다시 연결하거나 정리합니다.
- 외장 저장 장치에 문제가 발생하면 연결을 복구한 뒤 AppPorts로 앱을 Mac에 되돌리는 방법을 시도할 수 있습니다.
