# 오픈 소스 라이선스

AppPorts는 이 훌륭한 오픈 소스 프로젝트들 위에 만들어졌습니다. 모든 작성자와 기여자에게 감사드립니다.

## 이 프로젝트 <a href="#이-프로젝트" id="이-프로젝트"></a>

- **AppPorts** — Apache License 2.0 — [보기](<https://github.com/wzh4869/AppPorts/blob/main/LICENSE>)

## 참고 및 사용한 서드파티 <a href="#참고-및-사용한-서드파티" id="참고-및-사용한-서드파티"></a>

- **Pearcleaner** — Apache-2.0 with Commons Clause — 디렉터리 용량 스캔 등 구현 참고, 라이선스에 Commons Clause 조건이 붙습니다 — [보기](<https://github.com/alienator88/Pearcleaner>)

## 문서 사이트 <a href="#문서-사이트" id="문서-사이트"></a>

- **VitePress** — MIT — 문서 프레임워크, Inter 글꼴 동봉 — [보기](<https://github.com/vuejs/vitepress>)
- **Vue.js** — MIT — 프런트엔드 프레임워크 — [보기](<https://github.com/vuejs/core>)
- **vitepress-theme-teek** — MIT — 사이트 테마와 아이콘 글꼴 — [보기](<https://github.com/Kele-Bingtang/vitepress-theme-teek>)
- **Sass** — MIT — 빌드 시에만 사용, 배포물에 미포함 — [보기](<https://github.com/sass/dart-sass>)
- **Inter** — SIL OFL 1.1 — 사이트 본문 글꼴, VitePress 제공 — [보기](<https://github.com/rsms/inter>)

## 아이콘과 글꼴 <a href="#아이콘과-글꼴" id="아이콘과-글꼴"></a>

- **AppPorts** — Apache-2.0 — 프로젝트에서 직접 만든 앱 아이콘
- **SF Symbols** — Apple — 앱 내부 아이콘, macOS 제공, Apple의 SF Symbols 이용 약관 적용
- **Inter** — SIL OFL 1.1 — 사이트 본문 글꼴
- **teek iconfont** — MIT — 사이트 아이콘 글꼴, 테마와 함께 배포

### Pearcleaner의 추가 조건 <a href="#pearcleaner의-추가-조건" id="pearcleaner의-추가-조건"></a>

Pearcleaner는 Apache 2.0 with Commons Clause로 배포됩니다. 이는 소스 공개형 fair-code 라이선스이며 OSI가 승인한 오픈 소스 라이선스가 아닙니다. Apache 2.0 조건에 더해 이 소프트웨어의 기능이 주요 가치인 제품이나 서비스를 ‘판매’하는 것을 금지합니다. 사용 시 다음을 포함한 라이선스 전문을 유지하세요.

```text
Software: Pearcleaner
License: Apache 2.0 with Commons Clause
Licensor: alienator88
```
