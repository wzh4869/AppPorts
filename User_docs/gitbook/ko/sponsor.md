# AppPorts 후원하기

AppPorts는 완전 무료 오픈 소스 프로젝트이며 광고도 없고, 어떤 상업적 프로모션도 넣지 않습니다. 개인이 여가 시간에 유지 관리하는 프로젝트로 상업적 수익은 없습니다.

AppPorts 덕분에 로컬 저장 공간 수십 GB를 아꼈다면, 아래 QR 코드를 스캔해 개발자에게 커피 한 잔을 대접해 주세요. **금액은 자유이며, 작은 마음도 큰 힘이 됩니다.** 여러분의 후원이 프로젝트를 계속 이어 가는 힘입니다.

## 후원자 <a href="#후원자" id="후원자"></a>

| 닉네임 | 금액 | 링크 |
| --- | --- | --- |
| 师杀 | CN¥350 | [https://space.bilibili.com/396481888](<https://space.bilibili.com/396481888>) |
| zed | CN¥50 | — |
| VC | CN¥8.8 | — |
| 符华 | CN¥0.63 | — |


이 페이지와 AppPorts의 「AppPorts 정보」 페이지는 같은 후원자를 표시합니다(금액이 높은 순, 금액이 같으면 후원 시각이 빠른 순). **금액은 이 페이지에서만 표시됩니다.**

## QR 코드로 후원하기 <a href="#qr-코드로-후원하기" id="qr-코드로-후원하기"></a>

<figure><img src="https://pic.cdn.shimoko.com/thanks.png" alt="후원 QR 코드" width="320" /><figcaption></figcaption></figure>

WeChat으로 스캔해 후원할 수 있습니다. **최소 금액은 없습니다** — 부담 없는 만큼만 부탁드립니다.

## 메시지 안내 <a href="#메시지-안내" id="메시지-안내"></a>

후원할 때 메시지(비고)에 **닉네임**을 남겨 주세요. **링크는 선택 사항**이며 GitHub 프로필, 블로그, SNS 등 무엇이든 좋습니다.

보내 주신 「닉네임 + 링크」는 위 목록과 AppPorts의 「AppPorts 정보」 페이지에 표시됩니다.

{% hint style="success" %}
**공개하고 싶지 않다면**

닉네임이 없으면 후원 정보를 표시하지 않습니다. 닉네임만 제공한 경우 링크 없이 이름을 표시합니다.
{% endhint %}

## 표시 순서 <a href="#표시-순서" id="표시-순서"></a>

후원자는 다음 순서로 정렬됩니다.

| 우선순위 | 정렬 기준 |
| --- | --- |
| 1 | 후원 금액이 높은 순 |
| 2 | 금액이 같으면 후원 시각이 빠른 순 |

{% hint style="success" %}
**금액에 제한은 없습니다**

금액에는 하한이 없고, AppPorts의 모든 기능은 누구나 무료로 사용할 수 있습니다.
{% endhint %}

AppPorts를 응원해 주시는 모든 분께 감사드립니다 ❤️
