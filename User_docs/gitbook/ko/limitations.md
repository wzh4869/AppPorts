# 호환성 및 제한 사항

## 시스템 요구 사항 <a href="#시스템-요구-사항" id="시스템-요구-사항"></a>

| 요구 사항 | 설명 |
|------|------|
| 최소 시스템 버전 | macOS 12.0 (Monterey) |
| 아키텍처 | Intel x86_64 / Apple Silicon (arm64) |
| 권한 | 전체 디스크 접근 권한 |
| 외장 저장 장치 | 외장 저장 장치가 하나 이상 필요 |

## 기능 호환성 <a href="#기능-호환성" id="기능-호환성"></a>

### macOS 버전별 <a href="#macos-버전별" id="macos-버전별"></a>

| 기능 | macOS 12.0 - 15.0 | macOS 15.1+ |
|------|:---:|:---:|
| 앱 마이그레이션(Stub Portal) | ✓ | ✓ |
| 데이터 디렉토리 마이그레이션(심볼릭 링크) | ✓ | ✓ |
| 컨테이너 데이터 마운트 마이그레이션 | ✓(마운트 시 관리자 암호 필요) | ✓(27에서는 암호 없이 동작 확인. 13~26은 개별 검증하지 않음) |
| 디렉토리 마이그레이션(사용자 지정 폴더) | ✓ | ✓ |
| 코드 서명 관리 | ✓ | ✓ |
| App Store 앱을 외장 저장 장치로 마이그레이션 | ✗ | ✓ |
| 외장 저장 장치에서 App Store 앱 직접 업데이트 | ✗ | ✓ |
| iOS 앱 마이그레이션 | ✓ | ✓ |

{% hint style="warning" %}
**macOS 15.1 이전 버전의 App Store 앱**

macOS 15.1(Sequoia) 이전 시스템에서는 App Store 앱을 외장 저장 장치에 직접 설치하는 기본 기능을 지원하지 않습니다. 꼭 마이그레이션해야 한다면 AppPorts 설정에서 “Mac App Store 앱 마이그레이션 허용”을 직접 켜야 합니다. 앱을 업데이트한 후에도 외부 사본을 교체하려면 다시 수동으로 마이그레이션해야 합니다.
{% endhint %}

### 앱 유형별 <a href="#앱-유형별" id="앱-유형별"></a>

| 앱 유형 | 마이그레이션 | 복원 | 자동 업데이트 | 설명 |
|----------|:---:|:---:|:---:|------|
| 기본 macOS 앱 | ✓ | ✓ | ✓ | 가장 높은 호환성 |
| Sparkle 앱 | ✓ | ✓ | 잠금 필요 | 잠그면 앱 내부 업데이트가 차단되므로 Mac으로 되돌린 후 업데이트해야 함 |
| Electron 앱 | ✓ | ✓ | 잠금 필요 | Sparkle 앱과 같음 |
| Chrome / Edge(자체 업데이터) | ✓ | ✓ | ✓ | 업데이터가 로컬에 설치하므로 외부 사본을 손상시키지 않음 |
| App Store 앱(macOS 15.1+) | ✓ | ✓ | ✓ | 기본 외장 설치 기능으로 App Store에서 직접 업데이트 가능 |
| App Store 앱(macOS <15.1) | ✓ | ✓ | 수동 필요 | 업데이트 후 다시 마이그레이션해야 함 |
| Mac용 iOS 앱 | ✓ | ✓ | ✓ | iOS Stub Portal 사용 |
| 시스템 앱 | ✗ | — | — | SIP로 보호되어 마이그레이션 불가 |

{% hint style="warning" %}
**보호된 앱 마이그레이션**

App Store 앱이나 root 소유 앱은 macOS 권한 때문에 AppPorts가 로컬 사본을 자동으로 삭제하거나 교체하지 못할 수 있습니다. 보호된 앱 안내가 표시되면 Finder에서 먼저 외장 저장 장치로 직접 이동한 뒤 AppPorts로 돌아와 로컬 링크를 만드세요.
{% endhint %}

{% hint style="success" %}
**Finder의 바로가기 화살표**

이전 AppPorts 버전은 앱 전체를 가리키는 심볼릭 링크로 실행 경로를 만들었을 수 있으므로 Finder에 바로가기 화살표가 표시됩니다. 현재 버전은 일반 `.app` 앱에 기본적으로 Stub Portal을 사용하여 로컬 실행 경로에 보통 화살표가 표시되지 않습니다. 여전히 화살표가 보이면 앱을 Mac으로 되돌린 뒤 다시 마이그레이션하는 것이 좋습니다.
{% endhint %}

{% hint style="success" %}
**“내보내기 대기”에 관하여**

“내보내기 대기” 상태는 앱 버전을 비교할 수 있고 같은 앱이라는 판단이 확실할 때 표시됩니다. AppPorts는 먼저 Bundle ID로 로컬 앱과 외부 앱을 대조하고, 필요하면 정규화한 앱 이름을 보조 기준으로 사용합니다. 버전 번호가 없거나 형식을 비교할 수 없거나 같은 이름의 앱이라도 Bundle ID가 다르면 이 상태를 표시하지 않습니다.
{% endhint %}

### 데이터 디렉토리 유형별 <a href="#데이터-디렉토리-유형별" id="데이터-디렉토리-유형별"></a>

| 데이터 디렉토리 유형 | 마이그레이션 방식 | 위험 |
|-------------|:---:|------|
| `~/Library/Application Support/` | 심볼릭 링크 | 중간 — 앱이 파일 잠금이나 SQLite WAL 로그를 사용할 수 있음 |
| `~/Library/Preferences/` | 심볼릭 링크 | 낮음~중간 — `cfprefsd` 캐시 때문에 이전 설정을 읽을 수 있음 |
| `~/Library/Containers/` | 마운트 | 중간 — 암호화하지 않은 외장 APFS 드라이브 필요. 앱을 처음 열 때 접근 허용 필요. 앱을 열기 전에 드라이브 연결 필요 |
| `~/Library/Group Containers/` | 마운트 | 중간 — 위와 같음. 공유 데이터는 같은 Team의 다른 앱에도 영향을 줌 |
| `~/Library/Caches/` | 심볼릭 링크 | 낮음 — 캐시 재생성 가능 |
| `~/Library/Logs/` | 심볼릭 링크 | 낮음 — 로그 파일만 포함 |
| `~/Library/WebKit/` | 심볼릭 링크 | 중간 — WebKit 로컬 저장소 |
| `~/Library/HTTPStorages/` | 심볼릭 링크 | 낮음 — 네트워크 세션 저장소 |
| `~/Library/Application Scripts/` | 심볼릭 링크 | 낮음 — 확장 기능 스크립트 |
| `~/Library/Saved Application State/` | 심볼릭 링크 | 낮음 — 윈도우 상태 복원 |
| `~/.npm`, `~/.m2` 등의 dot-folder | 심볼릭 링크 | 낮음 — 개발 도구 캐시 |
| 사용자 홈 디렉토리의 사용자 지정 폴더 | 심볼릭 링크 | 내용에 따라 다름 — 쓰기 중인 앱이나 도구를 마이그레이션 전에 종료해야 함 |

{% hint style="warning" %}
**중요한 데이터가 있는 디렉토리**

WeChat 채팅 기록, 가상 머신 이미지, 게임 라이브러리, 데이터베이스, 모델 캐시 등은 크기가 크고 쓰기 작업이 잦으며 경로나 파일 잠금에 민감합니다. 마이그레이션 전에 별도 백업을 만드세요. 이후 앱에서 데이터 이상을 알리면 우선 로컬로 복원한 다음 원인을 확인하는 것이 좋습니다.
{% endhint %}

{% hint style="warning" %}
**컨테이너 데이터는 마운트 마이그레이션만 지원**

`~/Library/Containers/`와 `~/Library/Group Containers/` 데이터를 심볼릭 링크로 옮기면 샌드박스 앱이 읽을 수 없습니다. 이전 버전은 재서명으로 이를 우회했지만, 그 결과 앱이 macOS 27에서 열리지 않을 수 있습니다. 1.9.0부터 이 두 디렉토리 유형에는 [마운트 마이그레이션](datamigrae/mount-migration.md)만 제공하며 샌드박스 앱의 재서명을 모두 거부합니다. 배경은 [컨테이너 데이터, 샌드박스 및 서명 신원](datamigrae/container-identity.md)을 참조하세요.
{% endhint %}

{% hint style="warning" %}
**사용자 지정 디렉토리 범위**

디렉토리 마이그레이션은 사용자 홈 디렉토리의 실제 폴더를 대상으로 합니다. 파일, 심볼릭 링크, 외부 대상 내부 경로, 시스템 디렉토리 또는 이미 관리 중인 항목을 포함하거나 그 안에 포함되는 경로는 선택할 수 없습니다.
{% endhint %}

{% hint style="warning" %}
**대상 디렉토리 충돌**

외부 디렉토리의 크기가 비슷하다는 이유만으로 자동으로 관리에 포함하거나 복원하지 않습니다. 외부 디렉토리의 AppPorts 메타데이터가 현재 작업과 완전히 일치할 때만 자동 복구를 계속합니다. 그렇지 않으면 실제 디렉토리 충돌로 간주하고 작업을 중단합니다.
{% endhint %}

## 마이그레이션할 수 없는 항목 <a href="#마이그레이션할-수-없는-항목" id="마이그레이션할-수-없는-항목"></a>

### SIP로 보호되는 항목 <a href="#sip로-보호되는-항목" id="sip로-보호되는-항목"></a>

| 경로 | 이유 |
|------|------|
| Safari, Finder 등의 macOS 시스템 앱 | 시스템 무결성 보호 |
| `~/Library/Containers/` 최상위 디렉토리 | macOS 시스템 보호 |

### 경로 참조를 포함하는 항목 <a href="#경로-참조를-포함하는-항목" id="경로-참조를-포함하는-항목"></a>

| 경로 | 이유 |
|------|------|
| `~/.local` | 실행 파일 경로 참조를 포함하므로 마이그레이션 후 명령줄 도구가 작동하지 않을 수 있음 |
| `~/.config` | 절대 경로 설정을 포함하므로 마이그레이션 후 도구 설정이 작동하지 않을 수 있음 |

## 외장 저장 장치 요구 사항 <a href="#외장-저장-장치-요구-사항" id="외장-저장-장치-요구-사항"></a>

| 요구 사항 | 설명 |
|------|------|
| 파일 시스템 | 앱 본체와 일반 데이터 디렉토리: APFS, HFS+, exFAT 사용 가능. **컨테이너 데이터: APFS만 지원** |
| 최소 공간 | 마이그레이션할 앱의 크기에 따라 다름 |
| 인터페이스 | USB, Thunderbolt, NVMe 지원 |
| 연결 유지 | 마이그레이션 후에도 외장 저장 장치를 연결해야 함. 연결되지 않으면 관련 앱을 시작할 수 없음 |

{% hint style="success" %}
**파일 시스템 권장 사항**

- **APFS**: 권장합니다. 컨테이너 데이터 마운트 마이그레이션을 지원하는 유일한 형식이며 성능도 가장 좋습니다.
- **HFS+**: 구형 Mac과 호환되지만 컨테이너 데이터는 마이그레이션할 수 없습니다.
- **exFAT**: 여러 플랫폼에서 사용할 수 있지만 컨테이너 데이터는 마이그레이션할 수 없습니다. Windows와 함께 사용하려면 별도의 APFS 파티션을 사용할 수 있습니다. exFAT가 드라이브 전체를 차지하면 시스템 기본 도구로 바로 축소할 수 없으므로 백업 후 다시 파티션해야 합니다. 이미 할당되지 않은 공간이 있다면 [파티션 조건](why-apfs.md#prepare-apfs)에 따라 APFS 파티션을 만들 수 있습니다.

컨테이너 데이터에 APFS만 사용할 수 있는 이유와 검토한 대안은 [외장 드라이브에 APFS가 필요한 이유](why-apfs.md)를 참조하세요.
{% endhint %}

### 네트워크 마운트 드라이브 <a href="#네트워크-마운트-드라이브" id="네트워크-마운트-드라이브"></a>

NAS, SMB, rclone, SFTP 등의 네트워크 마운트 드라이브는 AppPorts의 주요 검증 대상이 아닙니다. 사용할 수는 있지만 마운트 안정성, 경로 일관성, 권한, 확장 속성과 심볼릭 링크 동작을 직접 확인해야 합니다. 지속적으로 데이터를 쓰는 디렉토리에는 네트워크 마운트 드라이브를 우선적으로 권장하지 않습니다.
