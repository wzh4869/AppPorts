# 遷移應用

應用遷移移動的是應用本體。聊天記錄、專案、模型和快取等資料可能仍在本機，需要另外使用[資料遷移](/docs/datamigrae/operation)。

## 遷移前 {#prepare}

連線外接儲存，在左側邊欄「目的地儲存」選擇外部應用庫資料夾，並透過側欄的「Mac 儲存 / 目的地儲存」確認剩餘空間；若目標是 SMB 網路共享或非 APFS 外接磁碟，可從「目的地儲存」選單建立或開啟 [APFS 應用庫映像](/docs/storage-guide#app-library-image) 來完整保留應用中繼資料。儲存工作並完全結束要遷移的應用，確保 AppPorts 從「應用程式」資料夾執行；重要內容先做好備份。系統應用和受保護的位置不適合直接移動，具體限制以 AppPorts 的提示為準。

## 遷移到外接磁碟 {#move}

1. 在側欄選擇「應用程式」，在「Mac 本地應用程式」清單選取應用。需要多選時，按住 Command 再逐個選擇。
2. 點選「遷移到外部」，檢查目標位置。若應用帶有需要確認的自更新器，按使用習慣選擇「非鎖定遷移」（預設）或「鎖定遷移」。
3. 若出現同名目標或版本選擇，先核對兩邊內容。不要把不能確認的副本當成垃圾刪除。
4. 等待 AppPorts 完成複製、檢查和本地入口建立。macOS 27 上下載應用自帶的隔離標記（quarantine）不會中斷遷移，能否首次開啟仍由系統安全策略決定。
5. 從 Finder 或 Dock 啟動應用，檢查開啟檔案等常用功能。

完成後，外部應用庫中能看到真實應用，本地保留[啟動入口](/docs/glossary#local-portal)。進度接近完成時仍可能在核驗或清理，請以最終結果為準。

如果應用不在預設掃描位置，可在「Mac 本地應用程式」標題列點選「+」新增掃描目錄，例如其他工具管理的安裝目錄。

任務可在側欄「任務中心」查看，詳細資料可「加入背景」，稍後再回來檢查。暫停與取消都需要等待安全處理；關閉詳細資料不等於取消任務，結束 AppPorts 也不等於讓進行中的遷移繼續執行。見[任務中心](/docs/datamigrae/operation#task-center)。

遷移前若提示目標磁碟缺少檔案屬性能力，請先讀[目標磁碟存不住的應用資訊](/docs/storage-capabilities)，再決定是否繼續；提示允許繼續，不代表應用一定相容。

## 遷移後如何更新 {#updates}

不同應用的更新方式並不相同。網易雲音樂、WorkBuddy 等已確認按一般方式處理的應用在遷移時不彈出鎖定選擇，未上鎖時直接顯示「已連結」；其他檢測到自更新器的應用會在遷移或接回前提供「非鎖定遷移」（預設醒目提示）和「鎖定遷移」兩種選擇。

| 情況 | 建議操作 |
| --- | --- |
| 非鎖定遷移下應用內更新異常 | 在「設定 → 背景代理」保持開啟「應用程式更新守護」：已適配的 ShipIt 更新失敗時，守護會驗證快取新版並嘗試完成安裝，結果寫入任務中心；失敗項可在任務詳細資料點選「復原更新」恢復已核驗舊版，或遷回本機更新。 |
| 鎖定遷移阻止了應用內更新 | 先結束應用，透過 AppPorts 遷回本機更新後再遷出；改為非鎖定遷移或遷回本機時，AppPorts 會一併清除關聯應用快取上的保護鎖。 |
| 更新程式把新版重新裝在本機 | 重新整理清單；出現「待遷出」時，核對版本並遷出本地新版。 |
| App Store 管理的外接應用（macOS 15.1+） | 結合 App Store 的外接安裝設定使用；AppPorts 可遷移任意大小（含小於 1 GB）的 App Store 應用。 |
| 較早系統上的 App Store 應用 | 在設定中確認是否允許遷移；更新後可能需要再次將本地新版遷出。 |

macOS 15.1 及以上可在 App Store 設定中開啟「下載並安裝大型 App 到獨立儲存磁碟」，並選擇與 AppPorts 相同的外接磁碟。App Store 自身僅對新下載大於 1 GB 的大型應用使用這項設定並直接管理更新；**AppPorts 遷移不受 1 GB 限制，小於 1 GB 的 App Store 應用也能遷入該磁碟的 `Applications` 目錄**。主介面的配置引導可選擇「不再提醒」，之後仍能在[設定與權限](/docs/settings#app-store)查看狀態並開啟 App Store 設定。

「應用程式更新守護」目前僅接手明確失敗且快取經簽名驗證通過的 ShipIt 更新，不保證涵蓋所有更新框架或全部 ShipIt 變體；詳見[更新保護與更新守護](/docs/migration-strategy/portal#updates)。

## 想遷回或恢復入口 {#restore-links}

- 把真實應用搬回內建磁碟：使用「遷移回本地」。
- 應用仍在外接磁碟，只缺本地入口：使用「連結回本地」。
- 只移除本地入口：在本地清單點選應用列右側的 `…`（「更多操作」）或右鍵選單，選擇「刪除本機入口」。

三種操作的區別和完整步驟見[還原、接回與解除連結](/docs/restore)。如果應用無法開啟，先檢查外接磁碟和[狀態提示](/docs/badges)，再按[問題排查](/docs/faq#launch)處理。

## 列表、大小快取與重複搜尋結果 {#search-cache}

應用頁頂部的「全部 / 已連結 / 未連結」只篩選清單，不會還原或刪除應用；切換篩選後，被隱藏的已選項不會繼續參與批次操作。本地與外部應用清單均可按名稱或大小排序。應用與工具目錄可顯示上次快取時間；磁碟內容已變化或大小看起來過時時，點選側欄底部的「重新整理快取」重新計算，不要把舊快取當成目前精確佔用。

Spotlight 同時顯示本機入口和外接磁碟應用時，可開啟「排除外接磁碟應用索引」面板查看檢查結果，再選擇處理未完成項。適用的普通獨立應用會移入外接磁碟專用的 `AppPorts.noindex` 應用庫，本機入口仍可使用；操作涉及真實應用位置，不只是隱藏一筆搜尋結果。套件目錄、App Store 與 iOS 應用暫不自動處理，衝突和失敗會單獨顯示。此操作不排除整塊磁碟，外接磁碟文件和照片的搜尋不受影響；系統索引重新整理仍可能需要等待。
