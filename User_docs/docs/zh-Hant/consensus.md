# 關於 AppPorts 的邊界與共識

AppPorts 做的，是改變 macOS 與許多應用程式在設計上的預設前提——在盡量不破壞原有簽名與沙盒機制的前提下，將原本預設駐留在內置磁碟的應用程式本體與資料，透過啟動殼、符號連結或 APFS 卷掛載等方式遷移到你指定的外部儲存空間。

::: warning 核心共識

但請記住：**AppPorts 不是神，它只是一把精密的手術刀。**

:::

## 無法窮舉的生態 {#ecosystem}

macOS 生態下有成千上萬款應用程式，每款軟體對路徑硬編碼、沙盒與權限校驗（Sandbox / TCC）、檔案所有權、簽名與自更新機制及背景守護行程的實作各不相同。我們無法窮舉測試所有應用程式，也無法保證 AppPorts 對你電腦裡的每一個軟體都 100% 相容。

## 風險與自由並存 {#risk-and-freedom}

脫離系統與應用程式預設的本機磁碟假設，意味著你需要承擔相應的不確定性。輕則應用程式閃退、設定重置、更新異常或權限失效；重則因外接磁碟意外斷開、離線寫入分岔或操作失誤，引發資料不可見、損壞甚至遺失。

## 對資料保持敬畏 {#respect-data}

在點擊任何遷移、還原、解綁、重簽名或清理舊副本等操作前，請務必仔細核對狀態與提示。操作前建議先查閱本站文件（如[快速開始](/docs/faststart)、[遷移應用](/docs/core)、[遷移資料](/docs/datamigrae/operation)與[外接磁碟與日常使用](/docs/storage-guide)）；你也可以點擊頁面右上角複製對應文件頁的 Markdown 內容發給 AI，讓它幫你快速解讀原理並評估目標應用程式的遷移風險。同時，請務必確認目標磁碟的連線穩定性，**操作前先做好備份；另外注意，Time Machine 預設只備份 Mac 內建硬碟，遷到外接磁碟裡的重要資料請自己另外留一份備份**。

## 回饋與共建 {#feedback}

AppPorts 的各項保護機制，正是在一次次真實實驗與踩坑中逐步打磨出來的。如果你在使用過程中遇到了異常、相容性問題，或者有更好的改進建議，歡迎透過 [GitHub Issues](https://github.com/wzh4869/AppPorts/issues)（提交 Bug 時建議透過「日誌 → 匯出診斷包」附帶診斷資訊）或其他社群管道回饋給我。

**AppPorts 賦予你掌控儲存空間的自由，但資料的最終安全，永遠掌握在你自己手中。**
