# 快速開始

準備一塊連線穩定、空間足夠的外接磁碟，以及執行 macOS 12 或更高版本的 Mac。本頁帶你完成安裝和第一次應用遷移；如果你只想移動聊天記錄、快取或模型等資料，可以在準備完成後轉到[遷移資料](/docs/datamigrae/operation)。

## 下載並安裝 {#install}

1. 從[AppPorts 下載頁](https://file.shimoko.com/AppPorts)獲取安裝包，也可以使用 [GitHub Releases](https://github.com/wzh4869/AppPorts/releases)。
2. 開啟安裝包，把 AppPorts 拖入 Mac 的「應用程式」資料夾。
3. 從「應用程式」開啟 AppPorts，按首次使用引導繼續。發起新遷移、操作磁碟映像和開啟權限引導前，AppPorts 會檢查自身是否位於「應用程式」資料夾；不要從安裝映像或暫存目錄長期執行。

## 準備權限與外接磁碟 {#permissions}

1. 連線外接磁碟，在左側邊欄「目的地儲存」選擇外部儲存資料夾；若目標是 NAS 共享或非 APFS 外接磁碟，也可以從同一選單建立或開啟 [APFS 應用庫映像](/docs/storage-guide#app-library-image)。
2. 點選側欄底部的設定齒輪（或按 `Command + ,`），檢視「準備狀況」卡片。按提示點選「開啟系統設定」，為 AppPorts 開啟「完全磁碟取用權限」，系統需要時再授予「App 管理」權限；如果系統清單中找不到 AppPorts，可直接把畫面上的引導圖示拖入系統設定清單。
3. 按提示重新開啟 AppPorts，可在「準備狀況」標題右側點選「檢查」核對狀態。

**只有容器資料的掛載遷移要求 APFS 儲存。** 普通應用和普通資料夾按各自條件檢查，不必為了第一次應用遷移就抹掉現有磁碟。格式不符合要求時，先閱讀[外接磁碟準備方法](/docs/storage-guide#apfs)。

## 完成第一次遷移 {#first-move}

1. 選擇一個你熟悉的應用，儲存工作並完全結束它。
2. 在側欄開啟「應用程式」，在「Mac 本地應用程式」清單中選取應用，點選「遷移到外部」。
3. 閱讀目標位置、更新方式或衝突提示，確認是你要移動的內容後繼續。
4. 等待複製、檢查和收尾全部完成。過程中保持外接磁碟連線，不要重新開啟該應用。
5. 從 Finder 或 Dock 開啟遷移後的應用，檢查主要功能是否正常。

完成後，真實應用存放在外部儲存，本地保留啟動入口；清單會顯示相應的[狀態徽章](/docs/badges)。遇到同名目標、權限不足或中斷時，先按提示處理，不要自行刪除兩邊的資料。

## 下一步 {#next}

- 應用能正常開啟：繼續瞭解[遷移後的更新方式](/docs/core#updates)。
- 想移動應用產生的資料：閱讀[遷移資料](/docs/datamigrae/operation)。
- 想恢復本地存放：閱讀[還原與接回](/docs/restore)。
- 操作沒完成或應用打不開：從[常見問題與排查](/docs/faq)查詢對應現象。

遷移會改變資料的存放位置，不會替代備份。日常使用前先連線外接磁碟，斷開前結束使用它的應用並正常退出磁碟。
