# 徽章与状态

徽章显示应用或目录的当前状态。不同项目可能有不同的徽章组合。

## 应用位置与更新保护 {#apps}

在「Mac 本地应用」和「外部应用库」中，徽章位于应用名称下方。有更新状态时，它排在第一位。点击「可用」或「未知」可以查看这款应用的更新方式或判断原因。徽章和说明都会跟随 AppPorts 选用的界面语言，支持全部 22 种语言。

把指针停在可点击的徽章上约 0.25 秒，也能打开和点击一样的内容；快速划过会取消触发。你可以把指针移进弹出的说明继续阅读，移出徽章和说明后预览会收起。悬停任务徽章会打开任务详情，悬停「签名已替换」会打开修复面板，具体修复操作由你在面板中选择。

| 看到的徽章 | 表示什么 | 接下来怎么做 |
| --- | --- | --- |
| 已链接 | 已有指向外部应用的本地入口（含未上锁的普通应用，以及网易云音乐、WorkBuddy 等按普通方式迁移的应用）。 | 连接外置盘后正常使用。 |
| 锁定迁移 | 已链接，且外部应用包当前启用了更新保护锁。 | 更新前阅读[应用更新说明](/docs/core#updates)；需更新时可先迁回本机。 |
| 非锁定迁移 | 已链接且未加锁的自更新应用。更新守护开启且显示「可用」时，列表会省略「非锁定迁移」徽章。 | 点击查看说明；可尝试应用内更新，配合设置中的“应用更新守护”可协助处理已适配的更新异常。 |
| 部分链接 | 文件夹内只有部分应用或组件已链接。 | 展开或查看对应项目，逐项确认。 |
| 孤立链接 | 本地入口还在，目前找不到外部目标。 | 先连接原外置盘（或重新挂载应用库映像）并刷新，不能据此断定文件已删除。 |
| 未链接、外部 | 外部应用尚无可用的本地入口。 | 需要时使用“链接回本地”。 |
| 自有 | AppPorts 使用自己的更新器。 | 请将 AppPorts 保留在本机的“应用程序”文件夹中。 |
| 可用 | 迁移后有已确认的更新方式。 | 点击查看是应用内更新、App Store 更新，还是先在本机更新再迁出。 |
| 检测中 | 正在确认当前版本的更新守护是否就绪。 | 守护就绪后会自动变为「可用」。 |
| 未知 | 当前无法确认迁移后的更新方式。 | 仍可尝试更新。点击徽章可查看守护是否已关闭。 |
| 待迁出 | 识别到本地真实应用比外部副本更新。 | 核对版本和目标，再将本地新版迁出。 |

Clash Verge、Visual Studio Code（含 Insiders）、Xcode 和 Claude 桌面端默认建议保留在本机，列表省略它们的更新状态徽章。选择迁出时会提示风险。

“锁定迁移”保护的是特定更新场景，并不替代备份；升级 AppPorts 不会自动解除此前已加锁的应用。“待迁出”也不是必须立即执行的命令。

## 应用类型 {#types}

| 徽章 | 含义与注意事项 |
| --- | --- |
| 运行中 | 应用正在运行，迁移或还原前先保存并退出。 |
| 系统 | macOS 系统应用，通常不适合迁移。 |
| 非原生 | 在 Mac 上运行的 iPhone／iPad 应用。支持范围受设备与系统限制。 |
| 商店 | 来自 App Store。 |

已实测自行更新的应用在关闭守护后仍显示「可用」，例如 IINA 使用 Sparkle，Qoder 使用 ShipIt。对于仅识别出同一框架的其他应用，关闭守护后显示「未知」。商店管理的外盘副本按 App Store 的设置判断。仅识别到 Electron 时仍显示「未知」。

## 签名状态 {#signing}

| 徽章 | 含义 | 建议 |
| --- | --- | --- |
| 签名已替换 | 检测到原开发者签名被本地重签替换。 | 打开“修复”或“查看修复步骤”，按[升级与修复](/docs/macos-27)处理。 |
| 签名待检查 | 当前签名或恢复材料的检查没有得到可靠结果。 | 先连接外盘，点击“检查签名”查看结果并保留备份；持续出现时提供诊断信息。 |
| 已重签名 | 当前识别为本地重签状态，但未归入上述开发者签名替换提示。 | 不代表已恢复官方身份，也不保证容器数据能访问。 |

签名状态与数据位置是两回事。“已挂载”不能证明应用签名正常，“签名已替换”也不能证明数据损坏。

已确认重签的应用，右键菜单保留“恢复原始签名”，不再同时提供重复重签入口；检查结果不明时先检查签名。新保存的官方原包在外盘，恢复前需接回保存它的盘，见[签名与修复](/docs/settings#manual-signing)。

## 数据目录与自选文件夹 {#data}

| 状态 | 表示什么 | 接下来怎么做 |
| --- | --- | --- |
| 本地 | 数据仍在本机。 | 核对用途后决定是否迁移。 |
| 已链接 | 原目录通过符号链接访问外部数据。 | 保持外盘在线。 |
| 已挂载 | 外部数据卷已接到原目录。 | 打开应用检查实际读写；若此前手动卸载过，也可恢复自动挂载。 |
| 待挂载 | 已找到数据卷，但尚未接到原目录（或此前手动卸载暂停了自动挂载）。 | 使用“挂载”。 |
| 外置盘未连接 | 暂时找不到受管数据卷；本地目录保持只读空目录保护。 | 连接原盘并检查卷是否可用；可读空目录不代表数据丢失。 |
| 待接回 | 外部数据仍在，本地入口需要重建。 | 核对目标后使用“接回”。 |
| 待规范 | 识别到受管链接，但位置需要整理。 | 阅读“整理”的确认说明；旧容器链接另见[经典模式](/docs/classic-mode)。 |
| 现有软链 | 已有符号链接，尚未按 AppPorts 的方式管理。 | 打开“链接详情”核对真实目标，按需要接管、还原或“强制解绑”。 |
| 用户目录入口 | 容器中指向桌面、下载、图片等个人目录的快捷入口，并非此应用独占的数据。 | 不统计目标大小，也不提供迁移或还原；不要把它当作普通空文件夹。 |
| 孤立链接 | 自选文件夹的链接目标暂时不可达。 | 先检查外盘、路径和连接。 |
| 未找到 | 配置中的目录目前不存在。 | 核对原位置，不要先新建同名空目录。 |
| 外部 | 自选文件夹的数据位于外部位置。 | 结合本地一侧状态判断是否需要接回。 |
| 目标冲突 | 目标位置已有其他内容。 | 确认两份内容的归属，不能直接覆盖。 |
| 保留副本 | 操作后还有需要保留或继续清理的副本。 | 按完成提示收尾，先确认有效数据在哪。 |

## 重要、推荐、可选 {#priority}

这是数据目录的重要程度提示，不是迁移成功率：**重要**表示影响应用核心功能，**推荐**表示通常有较大空间收益，**可选**表示可能较小或可重建。迁移任何一类都需要先退出相关程序。

例如，“推荐 + 本地”只是说这个本地目录值得查看；“已链接 + 运行中”则说明外部应用正在使用。需要改变存放位置或恢复入口时，见[还原、接回与解除链接](/docs/restore)。
