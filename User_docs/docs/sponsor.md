# 赞助 AppPorts

AppPorts 完全免费、开源、无广告，也没有接入任何商业推广。项目由个人在业余时间维护，没有任何商业收入。

如果 AppPorts 帮你省下了几十 GB 的本地空间，欢迎扫码请作者喝杯咖啡 —— **金额不限，一分也是心意**。你的支持，是项目持续更新的动力。

## 扫码赞助 {#section-2}

![赞助二维码](https://pic.cdn.shimoko.com/thanks.png)

使用微信扫码即可赞助。**没有最低金额要求**，多少随意，量力而行就好。

## 留言说明 {#section-3}

赞助时，请在留言（备注）中写下你的**昵称**；**个人链接可选**，GitHub 主页、个人博客、社交账号等都可以。

收到赞助后，我们会把「昵称 + 链接」收录，并展示在上面的名单以及 AppPorts 的「关于 AppPorts」页面中，感谢每一份支持。

::: tip 不想公开也没关系
未提供昵称且未留言时，我们不会展示赞助信息；未提供昵称但留有留言时，仅在本页匿名展示你的留言与金额，不会出现在 AppPorts 应用内和 GitHub 名单中。提供昵称但没有链接时，仅展示昵称，不附带跳转链接。
:::

如需补充或修改赞助名单中的昵称、备注留言、个人链接，或申请在实名与匿名展示之间切换，建议优先发送邮件至 [a@shimoko.com](mailto:a@shimoko.com)，也可通过 [GitHub Issue](https://github.com/wzh4869/AppPorts/issues/new?template=04-sponsor.yml) 提交申请。无论申请哪种修改，均请一并注明**至少精确到小时的付款时间**、原昵称（或原留言）及需要修改的内容，以便核对赞助记录。

## 展示顺序 {#section-4}

赞助者按以下规则排序：

| 优先级 | 排序规则 |
| --- | --- |
| 1 | 赞助金额从高到低 |
| 2 | 金额相同时，按赞助时间从早到晚 |

::: tip 金额不设门槛
赞助金额没有下限，也不影响你使用 AppPorts 的任何功能——它始终对所有用户完全免费。
:::
