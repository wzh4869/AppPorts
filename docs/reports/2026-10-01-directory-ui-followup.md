# 应用数据目录界面修正

日期：2026-10-01。工作树：`codex/migration-safety`。

## 三项反馈及修正

1. 微信容器中的 Desktop、Pictures、Downloads 经只读 readlink 核实，分别指向用户的同名个人目录。这些是用户目录入口，不是应用独占数据。现在显示“用户目录入口”和“不计入应用数据”，不扫描其目标、不显示个人目录总大小，不提供迁移和还原，随结构开关隐藏。识别要求精确容器层级、名称及目标匹配；受管链接、恢复记录不会被当成这种入口。
2. 父目录大小原本只统计同卷普通文件，不跨子挂载卷或子软链。因此 xwechat_files 的 442 kB 与挂载子目录的 10.97 GB 不是同一个统计范围。现在各行明确显示“本卷大小”或“目标大小”，并在说明中解释不包含子挂载卷、各行不能直接相加；可释放空间算法保持原样。这里统计逻辑文件大小，不承诺等于实际物理占用。
3. 原实现先构造完整树再保留匹配项祖先，把应隐藏的骨架重新带回，只显示为灰色。现在先过滤不可见节点，再重建最近可见祖先层级，最后处理搜索。关闭开关会真正减少行数，业务目录提升显示并保留路径上下文；受管、恢复、读取失败及冲突项仍然可见。

两个开关保持并排。新增说明覆盖现有 22 种语言。状态筛选与排序使用实际显示标签。
